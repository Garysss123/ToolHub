常見問題

這個音訊編輯器真的完全免費嗎？
是的，完全免費、免安裝、無需註冊。所有音訊處理都在你的瀏覽器中完成，使用 Web Audio API 和 Canvas 技術，不需要任何伺服器支援。
我的音訊檔案會被上傳到伺服器嗎？
不會。所有檔案只存在於你的裝置記憶體中。當你關閉頁面或重新整理，檔案就會消失。我們不會上傳、儲存或分享你的任何音訊資料。
支援哪些音訊格式？
支援 MP3、WAV、FLAC、OGG（Vorbis）、AAC、M4A（AAC）、WebM Audio（Opus）。匯出支援 WAV（無損）、OGG（有損壓縮）以及低品質 MP3 格式。
我可以編輯多長的音訊？
理論上沒有限制，但瀏覽器記憶體是主要瓶頸。一般建議處理 30 分鐘以下的音訊以獲得最佳體驗。更長的音訊可能需要分段處理。
如何剪輯音訊？
在波形上按下滑鼠拖曳選取範圍，然後使用工具列的 Trim、Delete、Copy 等功能。你也可以直接在「Trim」欄位輸入起訖秒數進行精確剪輯。
音效（Effects）是即時的嗎？
是的，所有效果都是即時處理的。當你啟用 EQ、Compressor、Reverb 等效果時，會立即聽到變化。最終匯出時，這些效果會永久套用到輸出檔案中。
支援多軌混音嗎？
支援輕量級多軌功能。你可以新增多個音軌，分別調整音量、靜音和獨奏，最後將所有音軌合併匯出為單一檔案。
哪些瀏覽器支援這個工具？
支援最新版的 Chrome、Edge、Firefox 和 Safari。建議使用 Chrome 或 Edge 以獲得最佳效能，特別是在處理長音訊和效果時。
鍵盤快捷鍵有哪些？
Space = 播放/暫停，Ctrl+Z = 復原，Ctrl+Y = 重做，Delete = 刪除選取，Ctrl+C = 複製選取，Ctrl+V = 貼上，Ctrl+D = 複製（Duplicate）。
什麼是 LUFS？為什麼重要？
LUFS（Loudness Units relative to Full Scale）是現代音訊響度的國際標準（ITU-R BS.1770）。串流平台如 Spotify、YouTube 都使用 LUFS 來標準化音量。本工具提供近似 LUFS 估算，幫助你掌握音訊的整體響度。

瀏覽器音訊編輯：Web Audio API 的強大能力

Mini Audio Studio 展示了現代瀏覽器在音訊處理上的驚人能力。透過 Web Audio API、Canvas 2D 和 OfflineAudioContext，我們在瀏覽器中實現了以往只有桌面 DAW（如 Audacity、Logic Pro）才能提供的功能。

核心技術

Web Audio API 是 W3C 標準的瀏覽器音訊處理介面，提供 AudioContext、AudioBuffer、BiquadFilterNode、DynamicsCompressorNode、ConvolverNode 等豐富的處理節點。這些節點可以自由串接，形成靈活的音訊處理管線（Audio Graph）。

OfflineAudioContext 允許在背景快速渲染音訊，無需即時播放，這使得效果套用、音訊分析與匯出都能在幾秒內完成。

應用場景

無論你是 Podcaster 想要修剪錄音、音樂人需要快速試聽效果、開發者要測試音訊處理演算法、還是一般使用者想轉換音訊格式，Mini Audio Studio 都能在瀏覽器中直接完成，無需安裝任何軟體。
