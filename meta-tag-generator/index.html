Meta Tag 常見問題

Meta Tag（Meta 標籤）是 HTML 文件 <head> 中的特殊標籤，提供網頁的後設資料給瀏覽器與搜尋引擎。雖然多數 Meta Tag 不會直接顯示在網頁上，但它們對 SEO 至關重要：

• Title Tag：搜尋結果中的藍色標題，是最重要的 SEO 排名因素之一。
• Meta Description：搜尋結果中的摘要文字，影響點擊率。
• Open Graph / Twitter Card：控制社群平台上的分享預覽。
• Canonical URL：防止重複內容問題，確保搜尋引擎索引正確的頁面。

正確的 Meta 標籤設定能提升搜尋引擎排名、增加社群分享曝光、改善使用者點擊意願。
Open Graph（OG） 是 Facebook 在 2010 年推出的通訊協定，讓網頁在 Facebook、LINE、LinkedIn 等社群平台上分享時，能顯示豐富的預覽資訊（標題、描述、圖片）。

• og:title：自訂分享標題，建議維持 40-60 字元。
• og:description：分享描述，建議 2-4 句話，不超過 200 字元。
• og:image：分享圖片，建議 1200×630 像素，會大幅增加點擊率。
• og:type：內容類型（website、article、product 等），幫助平台正確呈現。

設定正確的 OG 標籤，可以讓網站連結在社群平台上更加美觀且具吸引力，有效提升社群流量。
Twitter Card 是 X（原 Twitter）的分享預覽協定，功能類似 Open Graph，但專為 X 平台設計。

• summary_large_image：大圖模式，適合內容網站與部落格。
• summary：小圖模式，適合個人資料或簡單頁面。

兩者差異：
• OG 被多數平台廣泛支援（Facebook、LINE、LinkedIn、Slack 等）。
• Twitter Card 只影響 X 平台上的分享預覽。
• 最佳做法：同時設定兩者，確保在所有平台都有最佳分享效果。如果未設定 Twitter Card，X 會自動使用 OG 資訊，但效果較差。
Canonical URL（標準網址，rel="canonical"）是用來告訴搜尋引擎：當有多個 URL 指向相同或非常相似的內容時，哪一個才是「正式」的版本。

為什麼重要？
• 防止因重複內容導致的 SEO 懲罰。
• 確保搜尋排名權重集中在單一 URL。
• 常見情境：https vs http、www vs non-www、UTM 參數追蹤、列印版本、分頁等。

使用方式：
<link rel="canonical" href="https://example.com/original-page/" />

每個頁面都應該有自指的 canonical URL（即使沒有重複內容問題），這是最佳實踐。
簡短答案：Google 已不使用 Keywords Meta Tag 作為排名因素。

Google 在 2009 年正式宣布不再將 Keywords Meta Tag 用於排名，原因是該標籤長期被 SEO 操作者大量濫用與堆砌關鍵字。

• Bing / Yahoo：仍可能使用 Keywords 標籤作為排名參考之一（但權重極低）。
• Yandex（俄羅斯）：曾表示 Keywords 在某些情況下仍有參考價值。
• 百度（中國）：可能仍使用 Keywords 作為輔助信號。

建議：可以維持 Keywords 標籤（無害），但不要花時間最佳化它。專注在 Title、Description、內容品質與使用者體驗才是正確的 SEO 策略。
