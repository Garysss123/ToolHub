QR Code／Barcode Reader完整使用指南

Code Reader 從相機畫面或圖片辨識 QR Code 與一維條碼。辨識結果只是資料內容，不代表網址、付款資訊或下載檔案安全；在開啟連結前應先檢查網域與完整字串。

操作步驟

  1. 允許相機或選擇清晰、完整的條碼圖片
  2. 讓碼面保持平整、充足光線並避免裁切留白
  3. 先閱讀解碼文字，再決定是否複製或開啟連結

實務建議與限制

模糊、反光、低對比與過度透視會降低辨識率。陌生 QR Code 可能導向釣魚網站，請勿自動信任掃描結果。

隱私與本機處理

影像與解碼結果在瀏覽器本機處理，不會上傳相機畫面。
