色彩理論簡介

色彩配色是設計中至關重要的一環。了解不同的配色方案可以幫助您建立和諧、專業的視覺作品。

單色

同一色相不同明度，最安全的配色

類似色

色相環相鄰顏色，和諧自然

互補色

色相環相對顏色，對比強烈

三角色

色相環 120° 分布，活潑豐富

四色

兩組互補色，豐富且平衡

方形

色相環 90° 間隔，均衡多元

使用說明

  1. 使用 Color Picker 或輸入 HEX / RGB / HSL 選擇主色。
  2. 切換 配色方案（單色、類似、互補、三角等）查看不同配色效果。
  3. 每個色票顯示 HEX / RGB / HSL，點擊即可複製。
  4. 點擊色票上的 鎖定圖示 可鎖定該顏色，重新 Random 時保留。
  5. 切換到 CSS Variables 或 Tailwind 色票 標籤，複製產生的程式碼。
  6. 使用 匯出 按鈕下載 PNG、SVG 或 JSON 格式。

常見問題

什麼是色階 50-900？
這是參照 Tailwind CSS 的色階命名方式。50 是最淺色（接近白色），900 是最深色（接近黑色），500 為基準主色。這樣的命名讓顏色在不同明度下保持一致色相，方便設計系統使用。
Monochromatic 和 Analogous 有什麼不同？
Monochrome（單色） 是同一色相下不同明度的變化，整體統一和諧。Analogous（類似色） 是使用色相環上相鄰的 2-3 個色相，產生自然柔和的漸變效果，常用於按鈕 hover 和背景層次。
如何將色票匯入 Tailwind 專案？
切換到 Tailwind 色票 標籤，複製產生的 CSS Variables，或直接將色值複製到您的 tailwind.config.js 中的 theme.extend.colors 區塊。
