Accessibility 建議

色覺差異與網站無障礙設計

色覺差異不是單一狀態。Protan 類型主要影響紅色感知，Deutan 類型主要影響綠色感知，Tritan 類型則影響藍黃辨識；Achromatopsia 與 Achromatomaly 會大幅降低或移除彩度。模擬工具利用色彩矩陣近似可能的視覺結果，適合在設計階段找出風險，但無法代表每個人的真實感受或醫療診斷。

可靠的介面不能只以紅、綠區分成功與失敗。請加入文字標籤、圖示、線條樣式、紋理或位置差異，並確保焦點、Hover 與圖表圖例仍能被理解。文字和背景還需另外通過 WCAG 對比度檢查；「模擬看得出來」不等於對比度符合標準。

建議檢查流程

  1. 先以並排模式快速掃描品牌圖、圖表與按鈕狀態。
  2. 切換八種模型，找出顏色合併後消失的邊界。
  3. 為關鍵狀態加入非色彩提示，再重新模擬。
  4. 搭配實際使用者測試與對比度檢查完成驗證。

常見問題

這是醫療診斷工具嗎？
不是。它只用色彩矩陣協助設計檢查，不能診斷個人的色覺狀態。
哪種色覺差異最常見？
紅綠色覺差異較常見，但產品仍應同時考量較少見的藍黃色覺與低彩度情境。
為什麼不能只用紅色與綠色？
部分使用者可能難以區分，應同時加入文字、圖示或形狀，讓資訊不依賴色相。
我的圖片會被上傳嗎？
不會，File API 與 Canvas 都在瀏覽器本機執行。
通過模擬就等於符合 WCAG 嗎？
不等於。還需要檢查文字對比、鍵盤操作、語意結構、替代文字與其他成功準則。
