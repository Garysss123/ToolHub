Unix Timestamp 轉換工具完整使用指南

Unix Timestamp 表示從 1970-01-01 00:00:00 UTC 起經過的時間，常見單位為秒或毫秒。轉換時最容易混淆的是單位與時區：時間戳本身代表瞬間，格式化文字才會依時區顯示不同日期。

操作步驟

  1. 確認來源是秒、毫秒或其他精度
  2. 輸入時間戳或日期並選擇要查看的時區
  3. 比對 UTC 與本地結果後再用於資料庫或 API

實務建議與限制

不要在沒有時區資訊的日期字串上做武斷假設。跨系統交換建議使用 ISO 8601 與明確的 Z 或 offset，並留意 32-bit 秒數的範圍限制。

隱私與本機處理

日期與時間戳在瀏覽器本機轉換，不會傳送行程或紀錄。
