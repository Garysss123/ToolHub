Color Toolkit 顏色工具箱完整使用指南

Color Toolkit 協助設計者在 HEX、RGB、HSL 等色彩表示之間轉換，從圖片擷取顏色並建立漸層。數值轉換可能因色域與四捨五入略有差異，實際呈現也受螢幕與瀏覽器色彩管理影響。

操作步驟

  1. 輸入色碼或載入圖片選取目標像素
  2. 比較不同格式與透明度，建立需要的色票或漸層
  3. 在實際背景上檢查對比，再複製 CSS 值

實務建議與限制

品牌色不只要看起來一致，也要建立可讀的文字搭配。對重要文字與控制項使用專用對比度檢查，避免只以色相區分狀態。

隱私與本機處理

圖片取色與色彩計算都在本機執行，不會上傳設計素材。
