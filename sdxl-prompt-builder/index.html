什麼是 SDXL 提示詞產生器？

SDXL 提示詞產生器是一款免費的 AI 繪圖 Prompt 建構工具，內建超過 900 組中英雙語詞庫，讓您透過點擊標籤即可快速組合出專業級的 Stable Diffusion 提示詞。無論是使用 SDXL、Illustrious XL、NoobAI、 Pony Diffusion、Animagine XL、Anima 還是 FLUX， 都能一鍵組合人物、服裝、姿勢、場景、光線與風格，並自動產生符合 A1111 / ComfyUI 語法的英文標籤輸出。

如何快速建立一組完整 Prompt？

  • 選擇模型：先在上方切換您使用的模型，品質起手式與建議負向會自動切換。
  • 點選標籤：從正向詞庫依序加入人物、髮型、服裝、姿勢、場景與風格標籤。
  • 調整權重：開啟「權重模式」點擊標籤，可循環調整 (標籤:1.2) 等權重語法。
  • 套用負向：一鍵套用所選模型的建議負向提示詞，避免低品質與畸形結果。
  • 複製輸出：將正向與負向分別貼入 WebUI 或 ComfyUI 即可開始生成。

六大模型提示詞攻略

SDXL 通用 泛用

基礎 SDXL 模型適用所有場景。品質起手式：masterpiece, best quality, highres, ultra-detailed, absurdres, sharp focus。 建議參數：DPM++ 2M Karras、步數 25–30、CFG 5–7、解析度 1024×1024。負向務必加入 bad hands, extra digits 等手部標籤。

Illustrious XL / NoobAI 動漫

目前社群最主流的動漫模型系，對 Danbooru 標籤理解極佳。品質起手式：masterpiece, best quality, amazing quality, very aesthetic, absurdres, newest。 品質詞建議放在提示詞結尾，場景複雜時可首尾各放一次。建議參數：DPM++ 2M Karras 或 SGM Uniform、步數 25–28、CFG 5–5.8。

Pony Diffusion 評分詞系

Pony 系列以 score_1 到 score_9 評分標籤訓練，正向務必寫入 score_9, score_8_up， 負向加入 score_4, score_5, score_6 排除低品質。建議參數：Euler A、步數 28–40、CFG 7–9、Clip Skip 2。

Animagine XL 動漫

Animagine XL 4.0 系動漫模型，支援年份標籤（year 2024）與畫風標籤。品質起手式： masterpiece, best quality, highly detailed, anime style, beautiful detailed face。 建議參數：DPM++ 2M Karras、步數 28–30、CFG 5–7、Clip Skip 2。

Anima 新一代 2B 參數

Anima（CircleStone Labs 與 Comfy Org）是新一代動漫模型，同時接受 Danbooru 標籤與自然語言描述。 官方建議起手式：masterpiece, best quality, score_7, safe，並以小寫、空格分隔標籤（score 標籤除外）。 注意避免過度堆疊畫質詞，豐富的內容標籤比負向堆疊更有效。建議參數：er_sde、步數 30–50、CFG 4–5、Clip Skip 1。

FLUX / 自然語言模型 自然語言

FLUX、Qwen-Image 等新一代模型偏好自然語言描述而非純標籤。您可以將詞庫點選的標籤串接成完整句子， 例如：a stunning anime masterpiece of a silver-haired knight, highly detailed, 8k, sharp focus, cinematic lighting。 FLUX 對負向提示詞較不敏感，負向只需少量品質詞即可。

提示詞權重語法教學

權重（Weight）是控制生成重點的核心語法。在本工具開啟「權重模式」後，點擊標籤會依序循環 0.8 → 1.2 → 1.5 → 2.0， 輸出形如 (masterpiece:1.2) 的 A1111 / ComfyUI 相容語法。權重越高，該元素在圖中的存在感越強； 0.8 以下則用於淡化不重要的元素。建議重點人物或核心風格使用 1.2–1.5，避免過高的權重導致構圖失衡。

負向提示詞 (Negative Prompt) 的重要性

負向提示詞描述您不希望出現的元素，是穩定生成品質的關鍵。常見負向元素包含： 畫質問題（lowres, jpeg artifacts, blurry）、解剖錯誤（bad anatomy, bad proportions）、 手部缺陷（bad hands, extra digits, missing fingers）、多餘元素（watermark, signature, text）等。 本工具已為每個模型預先準備「建議負向」，切換模型後可一鍵套用。

提升畫質的進階技巧

  • 品質詞優先：務必將 masterpiece, best quality 等品質詞置於提示詞開頭（Illustrious 系建議結尾）。
  • 內容大於負向：具體描述姿勢、服裝、人物數量的正向提示，比堆疊負向更能穩定輸出。
  • 控制標籤數量：單一畫面建議 20–40 個標籤，過度堆疊會稀釋每個元素的效果。
  • 使用參數建議：參考本工具各模型的 CFG、步數與取樣器建議，作為調參起點。
  • 搭配其他工具：生成前可先使用 色票產生器 規劃色彩方案，或用 圖片轉換工具 後製作品。

常見問題 (FAQ)

SDXL 提示詞產生器支援哪些 AI 繪圖模型？
支援六種主流模型：SDXL 通用、Illustrious XL / NoobAI、Pony Diffusion、Animagine XL、Anima（Anima-xz 系列）以及 FLUX / 自然語言模型。切換模型後，品質起手式、建議負向與生成參數建議都會自動切換。
Illustrious XL 或 NoobAI 的品質詞該怎麼寫？
建議使用 masterpiece, best quality, amazing quality, very aesthetic, absurdres, newest。品質詞建議放在提示詞結尾，場景複雜時可放在開頭與結尾各一次。
Pony Diffusion 為什麼要用 score_9 評分詞？
Pony 系列以 score_1 到 score_9 的評分標籤訓練，score_9 代表最高的美感品質。正向寫入 score_9, score_8_up，並在負向加入 score_4, score_5, score_6 以避免低品質結果。
Anima 模型的提示詞跟 SDXL 有什麼不同？
Anima 同時接受 Danbooru 標籤與自然語言描述，建議小寫 + 空格分隔標籤，並避免過度堆疊畫質詞。官方建議起手式：masterpiece, best quality, score_7, safe，CFG 4–5、步數 30–50。
Negative Prompt 負向提示詞是什麼？為什麼重要？
負向提示詞描述您不希望出現的元素，例如 lowres, bad anatomy, bad hands, watermark, text 等。它能有效減少畸形手指、重複物件與浮水印等常見瑕疵，是穩定生成品質的關鍵。
提示詞權重 Weight 要怎麼使用？
開啟本工具的「權重模式」後，點擊詞庫標籤即可依序循環 0.8 → 1.2 → 1.5 → 2.0 權重，輸出 (標籤:權重) 的 A1111 相容語法。權重越高代表該元素越被強調。
CFG Scale、Steps 與 Sampler 要怎麼設定？
各模型建議值不同：Illustrious 建議 CFG 5–5.8、步數 25–28、DPM++ 2M Karras；Pony 建議 CFG 7–9、步數 28–40、Euler A；Anima 建議 CFG 4–5、步數 30–50、er_sde。切換模型時工具會自動顯示對應建議。
生成圖片出現手指或變形問題該怎麼辦？
先確認負向已包含 bad hands, extra digits, missing fingers, bad anatomy；接著檢查正向是否堆疊過多畫質詞；最後可提高 CFG 或步數，並改用更穩定的取樣器如 DPM++ 2M Karras。
