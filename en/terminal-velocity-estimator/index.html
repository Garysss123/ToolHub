Reproduce the built-in example

Start with Mass = 80; Gravity = 9.80665; Fluid density = 1.225; Drag coefficient = 1; Frontal area = 0.7, then run Terminal Velocity Estimator. Change one input at a time so the effect on the result remains traceable.

After validating mass, gravity, fluid density, drag coefficient, frontal area, the page displays its result in the output workspace and enables the relevant copy or download action.

Formula and variable relationship

Uses a quadratic drag model where gravity and drag balance. The implemented expression is “Math.sqrt(2*mass*g/(rho*cd*area))”. The page validates mass, gravity, fluid density, drag coefficient, frontal area before formatting the result in m/s.

Sensitivity check: change only mass from 80 kg to 88 kg. With every other input unchanged, terminal velocity moves from 42.776 to 44.864 m/s. This provides a reproducible input-to-result check.
