LINE Texture Image Processing Suite Complete User Guide

The LINE texture image processing suite helps organize illustrations into commonly used texture sizes, handle transparent backgrounds, borders, and output formats. The specifications for official submission for review may be updated, and the latest specifications of LINE Creators Market should still be used before submission.

Operation steps

  1. Add original illustrations and crop out unwanted white space or background
  2. Check transparent edges, subject size and reduced legibility
  3. Output the images according to the intended use, and then check the size and file format one by one.

Practical suggestions and limitations

Stickers will be displayed in a smaller size in the chat interface, and thin lines and small text will easily disappear. It is recommended to use clear outlines, sufficient white space and high contrast to avoid translucent edges.

Privacy and native processing

Image cropping and transparency processing all use the native Canvas, and unpublished characters or creative materials will not be uploaded.
