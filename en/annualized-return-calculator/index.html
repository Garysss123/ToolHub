Formula and variable relationship

Compound-annualizes a total return observed over a given number of days. The implemented expression is “(Math.pow(1+totalReturn/100,365/days)-1)*100”. The page validates holding-period return, holding days before formatting the result in %.

Sensitivity check: change only holding-period return from 12 % to 13.2 %. With every other input unchanged, annualized return moves from 18.81 to 20.751 %. This provides a reproducible input-to-result check.
