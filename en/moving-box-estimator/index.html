Formula and variable relationship

Estimates box count from item volume, box capacity, and packing fill ratio. The implemented expression is “Math.ceil(totalVolume/(boxVolume*(fill/100)))”. The page validates total item volume, box capacity, packing fill ratio before formatting the result in boxes.

Sensitivity check: change only total item volume from 1800 L to 1,980 L. With every other input unchanged, suggested boxes moves from 38 to 42 boxes. This provides a reproducible input-to-result check.
