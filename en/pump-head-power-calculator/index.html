Formula and variable relationship

Calculates pump input power for water from flow, head, and efficiency. The implemented expression is “9.80665*(flow/1000/3600)*head/(efficiency/100)”. The page validates flow rate, total head, pump efficiency before formatting the result in kW.

Sensitivity check: change only flow rate from 50 m³/h to 55 m³/h. With every other input unchanged, input power moves from 0.006 to 0.006 kW. This provides a reproducible input-to-result check.
