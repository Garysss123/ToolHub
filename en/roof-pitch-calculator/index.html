Formula and variable relationship

Converts rise and horizontal run into a roof pitch angle. The implemented expression is “Math.atan(rise/run)*180/Math.PI”. The page validates rise, run before formatting the result in °.

Sensitivity check: change only rise from 30 cm to 33 cm. With every other input unchanged, pitch angle moves from 16.7 to 18.26 °. This provides a reproducible input-to-result check.
