Reproduce the built-in example

Start with Area per cable = 80; Cable count = 24; Tray internal width = 300; Tray internal height = 60, then run Cable Tray Fill Calculator. Change one input at a time so the effect on the result remains traceable.

After validating area per cable, cable count, tray internal width, tray internal height, the page displays its result in the output workspace and enables the relevant copy or download action.

Formula and variable relationship

Divides total cable cross-section by tray internal cross-section. The implemented expression is “cableArea*count/(trayWidth*trayHeight)*100”. The page validates area per cable, cable count, tray internal width, tray internal height before formatting the result in %.

Sensitivity check: change only area per cable from 80 mm² to 88 mm². With every other input unchanged, fill percentage moves from 10.67 to 11.73 %. This provides a reproducible input-to-result check.
