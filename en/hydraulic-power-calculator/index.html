Formula and variable relationship

Calculates hydraulic input power from system pressure, volumetric flow, and total efficiency. The implemented expression is “pressure*flow/(600*(efficiency/100))”. The page validates system pressure, volumetric flow, overall efficiency before formatting the result in kW.

Sensitivity check: change only system pressure from 160 bar to 176 bar. With every other input unchanged, hydraulic input power moves from 14.634 to 16.098 kW. This provides a reproducible input-to-result check.
