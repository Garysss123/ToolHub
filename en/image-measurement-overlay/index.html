How to use this tool?

  1. Enter the data according to the field prompts and select the required processing method.

Suitable use cases

Product photos, floor plans, microscopic images, construction records and dimensional communication. All processing is completed in the current page, which is especially suitable for workflows that do not want to post internal data to remote services.
