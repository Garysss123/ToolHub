Reproduce the built-in example

Formula and variable relationship

Divides luminous flux by input power to calculate efficacy. The implemented expression is “lumens/watts”. The page validates luminous flux, input power before formatting the result in lm/W.

Sensitivity check: change only luminous flux from 1600 lm to 1,760 lm. With every other input unchanged, luminous efficacy moves from 106.67 to 117.33 lm/W. This provides a reproducible input-to-result check.
