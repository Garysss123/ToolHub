CIDR 網路基礎教學

什麼是 CIDR？

CIDR（Classless Inter-Domain Routing，無類別域間路由）是一種 IP 位址分配與路由選擇的方法，於 1993 年引入以取代傳統的 Class A / B / C 定址架構。CIDR 使用 {IP}/{Prefix} 表示法，例如 192.168.1.0/24，其中 /24 表示前 24 個位元為 Network Bits。

Subnet Mask（子網遮罩）

Subnet Mask 是一個 32 位元的二進位數字，用於將 IP 位址劃分為網路位址與主機位址。Network Bits 設為 1，Host Bits 設為 0。例如 /24 的 Subnet Mask 為 255.255.255.0。

Prefix Length（前綴長度）

Prefix Length 是 CIDR 表示法中斜線後面的數字，代表 Network Bits 的數量。IPv4 的 Prefix Length 範圍為 0-32，IPv6 為 0-128。前綴越長，網路越小，可用 Host 越少。

為什麼不用 Class A / B / C？

傳統的 Class 定址（Class A：/8、Class B：/16、Class C：/24）過於僵化，會造成大量的 IP 浪費。例如一個組織需要 300 個 IP，Class C（254 個 Host）不夠用，但 Class B（65,534 個 Host）又遠遠超出所需。CIDR 允許任意長度的前綴，實現更彈性的 IP 分配，有效延緩 IPv4 位址枯竭。

常見問題 (FAQ)

什麼是 Network Address？
Network Address 是子網中第一個 IP 位址，所有 Host Bits 皆為 0。它代表整個網路本身，不能用於分配給主機。在 IPv4 中，它與子網遮罩做 AND 運算得到。
什麼是 Broadcast Address？
Broadcast Address 是子網中最後一個 IP 位址，所有 Host Bits 皆為 1。用於向該子網內所有主機發送廣播封包。IPv6 沒有 Broadcast，而是使用 Anycast 與 Multicast 替代。
為什麼可用 Host 數量是「總 IP 數 - 2」？
每個 IPv4 子網有兩個保留位址不能分配給主機：Network Address（Host Bits 全 0）與 Broadcast Address（Host Bits 全 1）。因此可用 Host 數量 = 2^HostBits - 2。例如 /24 有 8 個 Host Bits，可用 Host = 2^8 - 2 = 254。

注意：/31（2 個 IP）和 /32（1 個 IP）是例外。RFC 3021 定義 /31 可用於點對點鏈路，兩個 IP 皆可使用。
IPv4 和 IPv6 的 CIDR 計算有什麼不同？
IPv6 使用 128 位元位址，Prefix Length 範圍為 0-128。與 IPv4 最大的差異是：
• IPv6 沒有 Broadcast Address
• 標準子網通常使用 /64（2^64 個 IP）
• 常見分配為 /48（給組織）或 /56（給家庭用戶）
• IPv6 總 IP 數量極大，通常不計算「可用 Host」，而是計算可分配的子網數量
什麼是 Wildcard Mask？
Wildcard Mask 是 Netmask 的反碼（bitwise NOT），用於 Cisco 網路設備的 ACL（存取控制列表）與 OSPF、EIGRP 等路由協定的 Network Statement。例如 Netmask 255.255.255.0 的 Wildcard 為 0.0.0.255，表示只要最後 8 位元可以任意匹配。
如何計算子網是否包含某個 IP？
將 IP 位址與 Netmask 做 AND 運算，如果結果等於 Network Address，則該 IP 屬於此子網。例如 192.168.1.15/24：
192.168.1.15 AND 255.255.255.0 = 192.168.1.0 = Network Address ✓
什麼是 VLSM（可變長度子網遮罩）？
VLSM 允許在一個網路中使用不同的 Prefix Length，對子網進行更細緻的切割。例如將 192.168.1.0/24 切割為 /25（126 個 Host）、/26（62 個 Host）與兩個 /27（30 個 Host），以最大化 IP 使用效率。
