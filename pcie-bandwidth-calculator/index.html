PCIe 知識百科

🔌 PCIe 是什麼？

PCIe（Peripheral Component Interconnect Express）是電腦內部的高速序列匯流排標準，用於連接主機板與各類擴充卡， 如顯示卡、SSD、網卡、影像擷取卡等。自 2003 年推出以來歷經多代演進，每一代傳輸速率翻倍。 不同於舊式的 PCI 並列匯流排，PCIe 採用序列點對點連接，每個裝置都有專屬通道，不會共用頻寬。

🔗 PCIe Lane 是什麼？

Lane（通道）是 PCIe 最基本的傳輸單元，每條 Lane 由兩組差分訊號對組成（一組發送、一組接收）， 可同時進行雙向傳輸。常見的 Lane 配置為 x1、x4、x8、x16，數字代表通道數量。 例如 x16 代表 16 條 Lane 並聯，可提供 16 倍的頻寬。CPU 通常提供 16~28 條直連 Lane， 其餘透過晶片組擴展。更多 Lane 數 = 更高頻寬，但也佔用更多實體接腳與 PCB 空間。

📊 PCIe 世代差異

每一代 PCIe 的傳輸率約為前一代的兩倍。PCIe 1.0 每 Lane 僅 2.5 GT/s（0.25 GB/s）， PCIe 5.0 已達到 32 GT/s（3.94 GB/s），而 PCIe 6.0 更進一步提升至 64 GT/s（7.88 GB/s）。 值得注意的是 PCIe 1.0/2.0 採用 8b/10b 編碼（效率 80%），而 PCIe 3.0 起改用 128b/130b 編碼（效率約 98.46%）， 這也是 3.0 相比 2.0 頻寬躍進超過兩倍的原因。

🎯 PCIe x8 和 x16 差在哪？

x16 提供 16 條 Lane，頻寬是 x8 的 2 倍。對高階顯示卡（如 RTX 4090/5090）， x8 模式可能成為輕微瓶頸，但多數中階 GPU 在 x8 下幾乎無感。 實測顯示，遊戲場景中 PCIe 4.0 x8 與 x16 的效能差異通常在 1~3% 內。 不過對 AI 訓練、影片剪輯等工作站應用，x16 能提供更充裕的資料吞吐空間。

⚡ PCIe 會影響 GPU 效能嗎？

一般情況下影響不大。以 RTX 4090 為例，在 PCIe 3.0 x16（≈15.75 GB/s）與 PCIe 4.0 x16（≈31.5 GB/s）之間， 遊戲幀數差異大多在 5% 以內。但如果使用 PCIe 3.0 x8（≈7.88 GB/s），則可能出現 10~20% 的效能下降， 尤其在 4K 解像度下更明顯。PCIe 5.0 x16 對當前 GPU 來說頻寬仍相當充裕，幾乎不存在瓶頸。

🆙 PCIe Gen5 值得升級嗎？

取決於用途。對 Gen5 NVMe SSD 用戶，升級至 PCIe 5.0 可釋放高達 15.8 GB/s 的儲存頻寬， 順序讀寫速度翻倍，大檔傳輸與影片編輯體驗明顯提升。對遊戲玩家，目前 PCIe 4.0 x16 的頻寬仍足夠， 短期內升級需求不高。但若考慮未來的高階 GPU 與 AI 加速卡，PCIe 5.0 能提供更佳的未來相容性。 建議新組裝的中高階電腦可直接選購支援 PCIe 5.0 的主機板。

對中階顯示卡（如 RTX 4060、RX 7600），PCIe 4.0 x8 在遊戲中幾乎沒有影響。對 RTX 4090 等級的高階卡，PCIe 4.0 x8 的效能損失約 2~5%，PCIe 3.0 x8 則可能達 10~15%。如果主機板只有 x8 插槽，建議確認顯示卡等級與 PCIe 世代。

直連 CPU 是指 PCIe Lane 直接從 CPU 引出，不經過晶片組（PCH），因此延遲更低、頻寬更完整。桌上型消費級 CPU 通常提供 16~28 條直連 Lane，主要分配給第一根 x16 顯示卡插槽。其餘 PCIe 插槽則由晶片組擴展，共享晶片組到 CPU 的 DMI 匯流排頻寬。

高品質的 PCIe 轉接卡（如 M.2 NVMe 轉 PCIe 轉卡）通常不會造成明顯效能損失。但若使用延長線（Riser Cable），品質好壞影響較大。PCIe 4.0/5.0 對訊號完整性要求更高，建議使用符合對應世代規格的延長線，否則可能出現降速或不穩定情況。

PCIe 6.0 標準已於 2022 年正式發布，傳輸率達 64 GT/s，並引入 PAM-4 調變技術與 FEC（前向錯誤修正）。首批支援 PCIe 6.0 的企業級產品預計 2025~2026 年間問世，消費級平台則可能等到 2027~2028 年。PCIe 6.0 主要鎖定 AI/ML、資料中心、高效能運算（HPC）等領域。
