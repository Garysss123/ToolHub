常見問題

Meta Description（Meta 描述）是搜尋引擎在搜尋結果中顯示的網站簡介。雖然不是直接的排名因素，但良好的 Description 能顯著提升點擊率（CTR）。建議長度在 120～158 個字元之間，包含目標關鍵字並自然呼籲行動（CTA）。沒有 Description 的頁面，搜尋引擎可能會自動擷取頁面中不相關的內容作為摘要。
Canonical（標準網址）告訴搜尋引擎哪個網址是「正版」。當同一頁面可透過多個網址存取時，Canonical 可防止重複內容問題，確保 SEO 權重集中於單一網址。缺少 Canonical 可能導致搜尋引擎分數分散，影響排名。
Open Graph（OG）是 Facebook 制定的 Meta 標籤協定，控制網頁在社交媒體分享時的標題、描述、圖片與預覽樣式。完善的 OG 標籤可讓網站在 Facebook、LINE、Slack 等平台呈現豐富的卡片式預覽，顯著提升社群分享的點擊率。
JSON-LD 是一種結構化資料格式，讓搜尋引擎更深入理解網頁內容。透過 JSON-LD 標記，網站可能獲得豐富摘要（Rich Snippets），如星評、FAQ、麵包屑等在搜尋結果中的特殊顯示。Google 明確推薦使用 JSON-LD 作為結構化資料的實作方式。
Meta Keywords 在現代 SEO 中已完全不被 Google、Bing 等主流搜尋引擎作為排名因素。Google 早在 2009 年就宣布不再使用 Keywords Meta 標籤。建議將精力集中在 Title 和 Description 的品質優化上。
建議的 Title 長度為 30～60 個字元（約 15～30 個中文字）。過短的 Title 無法完整傳達頁面內容，過長則可能在搜尋結果中被截斷。理想的 Title 應包含主要關鍵字、品牌名稱，並在開頭放置最重要的資訊。
Twitter Card 是 Twitter/X 專用的 Meta 標籤協定，控制網站在 Twitter 時間軸上的預覽樣式。雖然 Twitter 也支援 OG 標籤作為後備，但使用專用的 twitter:card、twitter:title、twitter:description 和 twitter:image 能確保在 Twitter 上獲得最佳顯示效果。

Title 標籤最佳做法

Title 標籤（<title>）是搜尋結果中最重要的元素，也是 SEO 的基石。每個頁面必須擁有獨一無二的 Title，這是搜尋引擎判斷頁面主題的首要依據。

推薦做法：

  • 長度控制：30～60 個字元（約 15～30 個中文字），避免被搜尋結果截斷
  • 關鍵字前置：將最重要的關鍵字放在 Title 開頭
  • 品牌結尾：在 Title 結尾加上品牌名稱（如「| ToolHub」）
  • 獨一無二：每個頁面應有專屬 Title，避免重複
  • 真實描述：Title 必須準確反映頁面內容，避免誤導使用者

Meta Description 最佳做法

Meta Description 雖然不是 Google 排名演算法的直接因素，但它對搜尋結果的點擊率（CTR）有重大影響。一個吸引人的描述可以讓您的搜尋結果在競爭對手中脫穎而出。

  • 長度建議：120～158 個字元，確保在搜尋結果中完整顯示
  • 包含關鍵字：自然地將目標關鍵字融入描述中，搜尋引擎會粗體顯示
  • 行動呼籲：加入 CTA（如「了解更多」、「立即試用」）提升點擊意願
  • 獨一無二：每個頁面都應有獨特的 Description，避免全部頁面使用相同描述
  • 避免空白：缺少 Description 時，搜尋引擎會自行擷取頁面內容，效果通常較差

Canonical 的用途

Canonical URL（標準網址）是解決重複內容問題的核心工具。當同一頁面可透過多個網址存取時（如 HTTP/HTTPS、www/non-www、結尾斜線、追蹤參數等），Canonical 標籤告訴搜尋引擎哪個網址是「正版」。

實作方式：在 <head> 中加入 <link rel="canonical" href="https://example.com/正確網址/" />。電子商務網站的分類、篩選、排序頁面尤其需要 Canonical 來防止權重分散。

Open Graph 是什麼？

Open Graph（OG）是 Facebook 於 2010 年推出的 Meta 標籤協定，現已成為社群分享的業界標準。透過 OG 標籤，您可以完全控制網頁在 Facebook、LINE、LinkedIn、Slack 等平台的預覽外觀。

必要的 OG 標籤：

  • og:title — 社群分享標題（建議 40～60 字元）
  • og:description — 社群分享描述
  • og:image — 分享圖片（建議 1200×630px，低於 5MB）
  • og:url — 頁面標準網址
  • og:type — 頁面類型（website、article 等）

JSON-LD 結構化資料入門

JSON-LD（JavaScript Object Notation for Linked Data）是 Google 推薦的結構化資料實作方式。透過在網頁中加入 JSON-LD，您可以幫助搜尋引擎更深入理解頁面內容，從而在搜尋結果中顯示豐富摘要（Rich Snippets）。

常見的 Schema 類型：

  • Organization — 組織/公司資訊（名稱、Logo、社群連結）
  • WebSite — 網站資訊（搜尋框、網站名稱）
  • BreadcrumbList — 麵包屑導航（搜尋結果中顯示路徑）
  • FAQPage — 常見問題（展開式問答）
  • Article — 文章（標題、作者、發布日期）
  • Product — 產品（價格、庫存、評價）

Viewport 與 Robots 設定要點

Viewport Meta 標籤是行動裝置友善的基礎，使用 <meta name="viewport" content="width=device-width, initial-scale=1"> 確保頁面在手機上正確縮放。自 Google 行動優先索引（Mobile-First Indexing）實施以來，Viewport 已成為必要標籤。

Robots Meta 標籤控制搜尋引擎的爬取與索引行為：index, follow（允許索引及跟隨連結）、noindex（禁止索引）、nofollow（禁止跟隨連結）。確認重要頁面未被 noindex 阻擋，並避免無關頁面（如管理後台）被索引。
