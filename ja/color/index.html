Color Toolkit 完全ユーザーガイド

Color Toolkit は、HEX、RGB、HSL などの色表現を相互変換し、画像から色を抽出したりグラデーションを作成したりできます。数値変換は色域や丸め処理によってわずかに差が生じる場合があり、実際の表示も画面やブラウザのカラーマネジメントに影響されます。

操作手順

  1. color code を入力するか image を読み込み、target pixel を選択します
  2. 異なる format と opacity を比較し、必要な color chip または gradient を作成します。
  3. 実際の background 上で contrast を確認し、CSS value を copy します。

実用的な提案と制限事項

ブランドカラーは見た目の一貫性だけでなく、読みやすい文字色との組み合わせも重要です。重要なテキストや control は専用の contrast check で確認し、状態の違いを hue だけで表現しないでください。

プライバシーと端末内処理

image color picking と color calculation はローカルで行われ、design asset は upload されません。
