JSON to CSV 変換 FAQ

JSON、CSV 形式変換、Excel import に関するよくある質問です。

JSON と CSV は目的がまったく異なる 2 種類の data format です：

  • JSONJSON（JavaScript Object Notation）は、ネストしたオブジェクトや配列を扱える構造化データ形式で、プログラム間のデータ交換や API 通信に適しています。
  • CSVCSV（Comma-Separated Values）はプレーンテキストの表形式です。各行が 1 record、各列が 1 field を表し、Excel、Google Sheets、database の import/export で広く使われます。

JSON から CSV への変換は、次のような場面に適しています。

  • API データを Excel や Google Sheets に取り込み、分析したい場合に利用できます。
  • machine learning や statistical analysis 用の dataset を準備します。
  • 非技術者と structured data を共有する用途（CSV なら Excel で直接開けます）。
  • database へのデータ取り込み（MySQL と PostgreSQL は CSV import に対応）
  • 意思決定者の確認用にレポートやスプレッドシートを作成

CSV は 2 次元 table format（row × column）で、nested structure を直接表せません。このツールを使って ドット記法でフラット化 ネストされたオブジェクトをフラットなフィールドへ自動変換する技術。

JSON 入力

{
  "user": {
    "name": "Gary",
    "age": 30
  }
}

CSV 出力

user.name,user.age
Gary,30

フラット化ルール：

  • object → 再帰的にフラット化し、Key をドットで連結します。例: profile.address.city
  • 配列 → field の増殖を避けるため、1セル内に JSON string として保存します。
  • Null → null value の設定に従って処理されます（empty string / null / N/A / 0）。

フラット化が行われた場合、ツール上部にオレンジ色で「Nested JSON has been automatically flattened.」と表示されます。

CSV を Excel へ import する方法はいくつかあります。

  1. 直接開く： .csv ファイルをダウンロードしたら、Excel で直接開いてください（UTF-8 エンコーディングを選択）。
  2. データからインポート： Excel → Data → Import from text/CSV → ファイル選択 → 区切り文字と Encoding を指定
  3. Google Sheets へドラッグ： .csv ファイルを Google Sheets へドラッグするだけで自動的に解析できます

UTF-8 BOM とは何ですか？

BOM（Byte Order Mark）はファイルの先頭に配置されます ﻿ マーク。CSV ファイルの場合：

  • BOM を有効化 → Excel が UTF-8 を自動認識し、中国語、日本語、その他の Unicode 文字を正しく表示します。
  • BOM なし → Excel がシステム既定 encoding（Big5 など）で開き、文字化けする場合があります。

💡 CSV を Excel へ読み込んだ後に中国語が文字化けする場合は、「UTF-8 BOM」を有効にして再度ダウンロードしてください。

CSV の C は Comma を意味しますが、実際には CSV で別の delimiter を使うこともできます。

  • カンマ（,） — 最も一般的な標準で、Excel と Google Sheets の既定形式でもあります。ただしデータにカンマが含まれる場合（例: 住所「Taipei City, Taiwan」）は quotation marks で囲む必要があります。
  • セミコロン（;） — 一部の欧州地域では小数点にコンマを使うため、Excel の既定区切り文字がセミコロンになっています。CSV が Excel で正しく列に分かれない場合は、セミコロンを試してください。
  • Tab（\t） — TSV（Tab-Separated Values）とも呼ばれます。データ内にコンマやセミコロンが頻繁に含まれる場合、Tab は安全な選択肢です。多くのデータベース取り込みツールでも TSV が優先的に扱われます。

💡 どれを使うか迷った場合は、まず comma を試してください。Excel で正しく表示されない場合は semicolon に切り替えてみてください。

よくある問題と解決方法は次のとおりです：

  • ネストされたオブジェクトデータがありませんか？ このツールは nested JSON を自動的に flatten します（例： profile.age), ただし JSON structure が複雑すぎる場合（5 level を超える deep nesting など）は、変換前に data を簡略化することを推奨します。
  • 配列データが切り詰められていますか？ 配列フィールドは JSON 文字列として 1 つのセルに保持されます（例： "["a","b","c"]")、Excel へ import しても自動展開されない場合があります。その場合は Excel の「データ → テーブル/範囲から」で追加処理できます。
  • 中国語文字が文字化けするのはなぜですか？ 「UTF-8 BOM」option を有効にして再 download すると、Excel が UTF-8 encoding を正しく認識できます。
  • CSV が Excel で 1 列にまとめて表示される場合は？ Use "semicolon (;)" or "Tab (\t)" as the delimiter instead, or manually specify the delimiter when importing into Excel.

JSON から CSV へ：データ分析と spreadsheet conversion の完全ガイド

現代のデータ処理ワークフローでは、JSON（JavaScript Object Notation）を使って CSV（Comma-Separated Values）はデータ交換の重要な 2 段階を表します。JSON は機械同士の通信形式、CSV は分析担当者とスプレッドシートをつなぐ橋渡しです。JSON から CSV への変換は、データ分析、バックエンド開発、BI における基本スキルです。

JSON とは何ですか？

JSON は軽量で language-independent な data exchange format です。使用するのはキーと値のペア（{"key": "value"}) と配列（[item1, item2]) を使って data を整理します。JSON の中核的な advantage は構造化能力— nested object を使って複雑なデータ関係を表現できます。これは平面的な CSV では直接表現できません。

現代の Web 開発では JSON があらゆる場所で使われています。RESTful API のレスポンス、データベースの検索結果（MongoDB、PostgreSQL JSONB）、設定ファイル（Node.js package.json), instant messaging（WebSocket）などで使われます。一方、このデータを Excel へ import したり統計分析したりする場合は、JSON を CSV へ変換する必要があります。

CSV とは何ですか？

CSV は表形式データをプレーンテキストで表す形式です。1970 年代までさかのぼる古い形式の 1 つでありながら、現在も非常に広く対応されています。CSV の設計は最小限で：1行に1 record、1列に1 field を置き、コンマで区切ります。。

CSV の利点は、汎用性: Excel、Google Sheets、Numbers、データベース管理ツール、Python Pandas、R、MATLAB など、表形式データを扱うほぼすべてのツールが CSV に対応しています。データ分野の「共通言語」とも言える形式で、長期保存やクロスプラットフォーム交換に適しています。

JSON と CSV の詳細比較

JSON

  • ネスト構造と複雑なデータ関係に対応
  • string、number、Boolean、Null、array、object など複数の data type に対応します。
  • 機械による解析効率が高く、API の標準的な形式です。
  • spreadsheet へ直接 import する用途には適していません。
  • 大きめのファイル（構造化マークアップを含む）

CSV

  • フラットな二次元表、1行につき1レコード
  • plain text data のみ対応します（すべての値を string として扱います）。
  • Excel で直接開いて編集できます
  • data analysis、statistics、report 作成に適しています。
  • file を軽量化でき、storage 使用量も小さく抑えられます。

実用例：ネスト JSON → CSV の自動フラット化

JSON 入力（ネストしたオブジェクトを含む）

CSV 出力（自動フラット化）

"id","name","email","profile.age","profile.city","profile.department","skills","active" "1","Alice Chen","alice@example.com","28","Taipei","Engineering","[""JavaScript"",""Python""]","true" "2","Bob Wang","bob@example.com","35","Taichung","Design","[""Figma"",""UI/UX""]","false"

ネストされたオブジェクトは自動的にフラット化されて profile.age、profile.city field。array は JSON string として保持されます。

データ分析における CSV の活用

  • Excel / Google Sheets: CSV を直接 open/import し、pivot table、chart、formula を使って data を探索します。
  • Python Pandas：pd.read_csv() データサイエンスのプロジェクトで最も一般的なデータ読み込み方法です
  • データベースをインポート:MySQL LOAD DATA INFILE、PostgreSQL COPY すべてのコマンドが CSV をネイティブ対応
  • BI ツール：Tableau、Power BI、Looker Studio など BI tool はすべて CSV を data source として利用できます
  • 機械学習：CSV は Kaggle competition、dataset publishing、model training input の標準形式です。
