Asphalt Tonnage Calculator の仕組み

Asphalt Tonnage Calculator は入力 parameter から asphalt mass を計算し、リアルタイム validation、読みやすい formula note、browser 内ローカル処理を提供します。

計算モデル

paved area、compacted thickness、density、waste から tonnage を見積もります。

推奨ワークフロー

  1. すべてのフィールドが表示されている単位を使用していることを確認します。
  2. example value を調整し、live result と input summary を確認してください。
  3. 結果をコピーしたら、前提条件を記録し、使用前に要件を再確認してください。

利用例

paved area、compacted thickness、compacted density、waste を扱う計画、比較、文書化、簡易確認に利用できます。

制限と検証

計算は次のモデルに従います。舗装面積、締固め厚さ、密度、ロス率から必要トン数を推定します。実案件では追加の係数、許容差、税、規定、専門家レビューが必要になる場合があります。

数式と変数の関係

舗装面積、締固め後の厚さ、密度、廃棄率から必要トン数を見積もります。実装式は「area*thickness/1000*density/1000*(1+waste/100)」です。ページでは舗装面積、締固め厚、締固め密度、廃棄率を検証し、結果を t で整形します。

感度チェック：paved area だけを 500 m² から 550 m² へ変更します。他の入力を変えない場合、asphalt mass は 61.688 から 67.856 t へ変化します。入力から結果までを再現できる確認例です。
