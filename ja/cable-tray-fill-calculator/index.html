Cable Tray Fill Calculator の仕組み

Cable Tray Fill Calculator は入力 parameter から fill percentage を計算し、リアルタイム validation、読みやすい formula note、browser 内ローカル処理を提供します。

計算モデル

ケーブル総断面積を Tray 内部断面積で割って占有率を求めます。

推奨ワークフロー

  1. すべてのフィールドが表示されている単位を使用していることを確認します。
  2. example value を調整し、live result と input summary を確認してください。
  3. 結果をコピーしたら、前提条件を記録し、使用前に要件を再確認してください。

利用例

area per cable、cable count、tray internal width、tray internal height を扱う計画、比較、文書化、簡易確認に利用できます。

制限と検証

計算は次のモデルに従います。ケーブル断面積の合計をトレイ内部断面積で割ります。実案件では追加の係数、許容差、税、規定、専門家レビューが必要になる場合があります。

数式と変数の関係

ケーブルの合計断面積をトレイ内部断面積で割って占有率を求めます。実装式は「cableArea*count/(trayWidth*trayHeight)*100」です。ケーブル 1 本あたりの断面積、本数、トレイ内部幅、内部高さを検証したうえで、結果を % で整形します。

感度チェック：area per cable だけを 80 mm² から 88 mm² へ変更します。他の入力を変えない場合、fill percentage は 10.67 から 11.73 % へ変化します。入力から結果までを再現できる確認例です。
