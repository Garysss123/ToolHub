雷までの距離推定ツールの仕組み

Lightning Distance Estimator は入力 parameter から推定距離を計算し、リアルタイム validation、読みやすい formula note、browser 内ローカル処理を提供します。

計算モデル

flash-to-thunder delay と温度補正した音速を使用します。

推奨ワークフロー

  1. すべてのフィールドが表示されている単位を使用していることを確認します。
  2. example value を調整し、live result と input summary を確認してください。
  3. 結果をコピーしたら、前提条件を記録し、使用前に要件を再確認してください。

利用例

flash-to-thunder delay、air temperature を使う計画、比較、文書化、簡易チェックに利用できます。

制限と検証

この計算は、稲光から雷鳴までの遅延時間と気温補正した音速から距離を求めるモデルに従います。実際のプロジェクトでは追加係数、公差、規格、専門家による確認が必要になる場合があります。

組み込み例を再現します

Flash-to-thunder delay = 9、Air temperature = 20 から始め、Lightning Distance Estimator を実行します。結果への影響を追跡できるよう、入力は 1 項目ずつ変更してください。

flash-to-thunder delay、air temperature を検証した後、結果を出力ワークスペースへ表示し、対応する copy または download 操作を有効にします。

数式と変数の関係

稲光から雷鳴までの遅延時間と、気温補正した音速から距離を求めます。実装式は「seconds*(331.3+0.606*temp)/1000」です。遅延時間と気温を検証してから km で結果を表示します。

感度チェック：flash-to-thunder delay だけを 9 s から 9.9 s へ変更します。他の入力を変えない場合、estimated distance は 3.09 から 3.4 km へ変化します。入力から結果までを再現できる確認例です。
