LINE Texture Image Processing Suite 完全ユーザーガイド

LINE スタンプ画像処理ツールは、イラストを一般的なスタンプ画像サイズへ整え、透過背景、余白、出力形式などを処理するのに役立ちます。公式の審査提出仕様は更新される可能性があるため、提出前には LINE Creators Market の最新仕様を確認してください。

操作手順

  1. original illustration を追加し、不要な white space または background を crop します。
  2. 透明な縁、被写体サイズ、縮小時の可読性を確認します
  3. 用途に合わせて画像を書き出し、その後サイズとファイル形式を1つずつ確認してください。

実用的な提案と制限事項

ステッカーはチャット画面では小さく表示されるため、細い線や小さな文字は見えにくくなります。明確な輪郭、十分な余白、高いコントラストを使い、半透明の縁は避けることをおすすめします。

プライバシーと端末内処理

画像 crop と transparency 処理はすべて native Canvas を使用し、未公開キャラクターや制作素材を upload しません。
