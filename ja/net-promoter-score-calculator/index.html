NPS（ネットプロモータースコア）計算ツールの仕組み

Net Promoter Score Calculator は指定したパラメータから NPS を計算し、リアルタイム検証、読みやすい数式説明、ブラウザ内ローカル処理を提供します。

計算モデル

promoter の割合から detractor の割合を差し引きます。

推奨ワークフロー

  1. すべてのフィールドが表示されている単位を使用していることを確認します。
  2. example value を調整し、live result と input summary を確認してください。
  3. 結果をコピーしたら、前提条件を記録し、使用前に要件を再確認してください。

利用例

promoters、detractors、total valid responses を使う計画、比較、文書化、簡易チェックに利用できます。

制限と検証

この計算は、推奨者の比率から批判者の比率を差し引くモデルに従います。実際のプロジェクトでは追加係数、公差、調査条件、専門家による確認が必要になる場合があります。

組み込み例を再現します

まず Promoters = 420、Detractors = 80、Total valid responses = 600 に設定し、Net Promoter Score Calculator を実行します。結果への影響を追跡できるよう、一度に変更する入力は 1 つにしてください。

promoters、detractors、total valid responses を検証した後、結果を出力ワークスペースへ表示し、コピーまたはダウンロード操作を有効にします。

数式と変数の関係

推奨者の比率から批判者の比率を引きます。実装式は「(promoters-detractors)/responses*100」です。promoters、detractors、有効回答総数を検証してから、指定された表示単位で結果を整形します。

感度確認：promoters だけを 420 people から 462 people に変更します。他の入力をすべて同じにすると、net promoter score は 56.7 から 63.7 に変化します。入力と結果の関係を再現して確認できます。
