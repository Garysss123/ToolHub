CIDR インターネット基礎チュートリアル

CIDR とは何ですか？

CIDR（Classless Inter-Domain Routing）は、従来の Class A/B/C アドレス体系を置き換えるため 1993 年に導入された IP アドレス割り当て・routing 方式です。CIDR は {IP}/{Prefix} 表記。たとえば 192.168.1.0/24、そのうち /24 先頭 24 bit が Network Bits であることを示します。

Subnet Mask

Subnet Mask は IP アドレスをネットワーク部とホスト部に分ける 32 bit の 2 進数です。Network Bits を 1、Host Bits を 0 にします。たとえば /24 Subnet Mask は 255.255.255.0。

Prefix Length（プレフィックス長）

Prefix Length は CIDR 表記のスラッシュ後の数字で、Network Bits の数を表します。範囲は IPv4 が 0〜32、IPv6 が 0〜128 です。prefix が長いほどネットワークは小さくなり、利用可能なホスト数も減ります。

なぜ Class A/B/C を使わないのですか？

従来のクラスフルアドレッシング（Class A: /8、Class B: /16、Class C: /24）は柔軟性が低く、多くの IP アドレスを無駄にします。たとえば組織が 300 個の IP を必要とする場合、Class C（254 Hosts）では不足しますが、Class B（65,534 Hosts）では過剰です。CIDR なら任意長のプレフィックスを使えるため、IP をより柔軟に割り当てられ、IPv4 アドレス枯渇を効果的に遅らせられます。

よくある質問（FAQ）

Network Address とは何ですか？
Network Address はサブネット内の最初の IP アドレスで、すべての Host Bits が 0 です。ネットワーク自体を表すためホストへ割り当てることはできません。IPv4 では IP アドレスとサブネットマスクの AND 演算で求められます。
Broadcast Address とは何ですか？
Broadcast Address はサブネット内の最後の IP アドレスで、すべての Host Bits が 1 です。同じサブネットの全ホストへブロードキャストパケットを送るために使います。IPv6 には Broadcast がなく、代わりに Anycast と Multicast を使用します。
available hosts が「total IPs - 2」になるのはなぜですか？
各 IPv4 サブネットには、ホストへ割り当てられない予約アドレスが 2 つあります。Network Address（Host Bits がすべて 0）と Broadcast Address（Host Bits がすべて 1）です。そのため利用可能なホスト数は 2^HostBits - 2 になります。たとえば /24 Host Bits は 8、利用可能な Hosts = 2^8 - 2 = 254。

注：/31（2 個の IP）と /32（1 IP）は例外です。RFC 3021 の定義 /31 ポイントツーポイントリンクで使用でき、両方の IP を利用できます。
IPv4 と IPv6 の CIDR 計算にはどのような違いがありますか？
IPv6 は 128-bit address を使い、Prefix Length は 0〜128 です。IPv4 との大きな違いは：
• IPv6 には Broadcast Address がありません
• 通常は標準的なサブネットを使用します /64（2^64 個の IP）
• 一般的な割り当ては /48（組織宛て）または /56（家庭ユーザー向け）
• IPv6 の IP アドレス総数は非常に大きいため、通常は「利用可能ホスト数」ではなく、割り当て可能なサブネット数を考えます。
Wildcard Mask とは何ですか？
Wildcard Mask は Netmask のビット反転（bitwise NOT）で、Cisco ネットワーク機器の ACL（Access Control List）や OSPF、EIGRP などのルーティングプロトコルの Network Statement で使われます。たとえば Netmask 255.255.255.0 ワイルドカードは 0.0.0.255, 最後の 8 bit が一致すれば任意の値にマッチすることを示します。
サブネットに特定の IP が含まれるか計算するには？
IP address と Netmask を AND 演算し、結果が Network Address と等しければ、その IP は subnet 内にあります。例：192.168.1.15/24：
192.168.1.15 AND 255.255.255.0 = 192.168.1.0 = Network Address ✓
VLSM (Variable Length Subnet Mask) とは何ですか？
VLSM を使うと、1つのネットワーク内で異なる Prefix Length を使い、より細かくサブネット分割できます。たとえば変更 192.168.1.0/24 切り詰め先 /25（126 ホスト）、/26(62 ホスト) 対 2 /27（30 Hosts）で IP 利用効率を最大化。
