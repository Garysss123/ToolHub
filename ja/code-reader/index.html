QR Code／Barcode Reader 完全ユーザーガイド

Code Reader はカメラ映像または画像から QR Code と 1D barcode を認識します。認識結果はあくまでデータ内容であり、URL、決済情報、ダウンロードファイルの安全性を保証するものではありません。リンクを開く前にドメインと文字列全体を確認してください。

操作手順

  1. カメラを許可するか、鮮明で全体が写ったバーコード画像を選択します
  2. code surface を平らにし、十分な照明を確保して、blank space を切り取らないようにします。
  3. decode した text を確認してから、copy または link を開くか判断してください。

実用的な提案と制限事項

ぼけ、反射、低 contrast、強すぎる perspective は認識率を下げます。見慣れない QR Code は phishing site へ誘導する可能性があるため、scan 結果を自動的に信用しないでください。

プライバシーと端末内処理

画像とデコード結果はブラウザー内でローカル処理され、カメラ映像がアップロードされることはありません。

QR Code/Barcode Reader の使い方は？
カメラを許可し、鮮明で全体が写った barcode を使用してください。コード面を平らにし、十分な照明を確保し、余白を切り取らないようにします。まず decoded text を確認し、その後にコピーまたはリンクを開くか判断してください。
