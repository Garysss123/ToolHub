工程能力指数計算ツールの仕組み

Process Capability Index Calculator は、指定パラメータから process capability cp を計算します。リアルタイム検証、読みやすい計算式メモ、ローカルブラウザ処理に対応しています。

計算モデル

specification width を 6 process standard deviation で割ります。

推奨ワークフロー

  1. すべてのフィールドが表示されている単位を使用していることを確認します。
  2. example value を調整し、live result と input summary を確認してください。
  3. 結果をコピーしたら、前提条件を記録し、使用前に要件を再確認してください。

利用例

upper specification limit、lower specification limit、process standard deviation を使う計画、比較、文書化、簡易チェックに利用できます。

制限と検証

この計算は、規格幅を工程標準偏差の6倍で割るモデルに従います。実際の工程能力評価では、分布、安定性、測定系などの前提も確認してください。

数式と変数の関係

仕様幅を工程標準偏差の 6 倍で割ります。実装式は「(usl-lsl)/(6*sigma)」です。ページでは上側規格限界、下側規格限界、工程標準偏差を検証してから、表示対象の次元に合わせて結果を整形します。

感度確認：upper specification limit だけを 10.5 から 11.55 に変更します。他の入力をすべて同じにすると、process capability cp は 1.389 から 2.847 に変化します。入力と結果の関係を再現して確認できます。
