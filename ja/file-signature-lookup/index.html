よくある質問（FAQ）

Magic Number とは何ですか？
Magic Number（マジックナンバー、file signature とも呼ばれます）はファイル先頭に置かれる固定バイト列で、ファイル形式を識別するために使われます。たとえば JPEG ファイルは必ず次の値から始まります。 FF D8 FF、PNG は次に基づきます 89 50 4E 47 先頭部分です。OS やアプリケーションはこれらのバイトを使って、ファイル内容を正しく解析する方法を判断します。
ファイル形式の判定に拡張子だけを使えないのはなぜですか？
ファイル拡張子は単なるテキストラベルで、誰でも変更できます。攻撃者は悪意あるプログラムを次のように偽装することがあります。 .jpg または .pdf, セキュリティ検査をすり抜ける可能性があります。Magic Number はファイルそのもののバイナリ特性であり、単純な rename では偽装できません。そのため、デジタルフォレンジックやセキュリティ解析では拡張子より Magic Number が重視されます。
偽装ファイルを見分けるには？
このツールの「Upload File」機能で疑わしいファイルを読み込むと、Magic Number を自動取得して実際の形式と照合します。判定された形式とファイル拡張子が一致しない場合（たとえば拡張子が .jpg 一方、Magic Number が ZIP と表示されるのに別形式の拡張子が付いている場合、ファイル名を変更して偽装している可能性があります。このツールはそのような不一致を自動的に警告します。
ZIP container format とは何ですか？ DOCX、APK、EPUB がすべて ZIP なのはなぜですか？
Microsoft Office 2007 以降の DOCX、XLSX、PPTX、Android の APK、電子書籍 EPUB などは、本質的には複数の XML ファイルやリソースを含む ZIP 圧縮コンテナです。これらの Magic Number はいずれも 50 4B 03 04（ZIP signature）。さらに区別するには container 内部構造を解析し、たとえば次が存在するか確認する必要があります [Content_Types].xml または AndroidManifest.xml およびその他の特徴的なファイル。
すべての Magic Number はファイル先頭にありますか？
必ずしもそうではありません。多くの形式では Magic Number は offset 0、つまりファイル先頭にありますが、例外もあります。たとえば TAR アーカイブの Magic Number は offset 257 bytes（string ustar), ISO 9660 disc image の識別文字列は offset 32769 にあります。このツールは異なる offset の Magic Number も自動検出し、識別精度を高めます。
このツールは file をサーバーへアップロードしますか？
いいえ。このツールは純粋なフロントエンドアプリで、ファイルの読み取りと分析はすべてブラウザ内で行われます。読み取るのはファイル先頭 64 bytes のみで、データはネットワークへ送信されません。機密ファイルの分析にも利用できます。
一般的な Magic Number には何がありますか？
最も一般的な profile signature の例：
• FF D8 FF — JPEG 画像
• 89 50 4E 47 — PNG 画像
• 25 50 44 46 — PDF ファイル
• 50 4B 03 04 — ZIP アーカイブ
• 4D 5A — Windows EXE 実行ファイル
• 7F 45 4C 46 — Linux ELF 実行ファイル
• CA FE BA BE — Java Class クラスファイル

Magic Number を理解する：ファイル形式判別の基礎

Magic Number とは何ですか？

Magic Number（File Signature とも呼ばれます）は、ファイル形式の規格で定義された固定のバイト列で、ファイル内の特定オフセット（通常は先頭）に置かれます。これはファイルの「DNA」のようなもので、拡張子に左右されず、実際のファイル形式を識別できます。

たとえば standard-compliant PDF file の最初の 4 byte は必ず 25 50 44 46（つまり文字列 "%PDF"）。PNG 画像の先頭 8 byte は必ず 89 50 4E 47 0D 0A 1A 0A。

なぜ拡張子だけを信用できないのですか？

ファイル拡張子（.jpg、.exe、.pdf など）はファイルシステム上のラベルにすぎず、名前を変更すれば誰でも書き換えられます。Windows は既知の拡張子を標準で非表示にするため、見分けにくくなる場合があります。実際のマルウェアでも、たとえば次のような名前が使われる可能性があります。 document.pdf.exe, while Windows only displays "document.pdf", misleading users to click.

Magic Number は、攻撃者がファイル形式全体を正しく偽装しない限り単純にはごまかせません。内部バイト構造まで整合させる必要があるため、情報セキュリティ分野では Magic Number の確認が基本的かつ信頼性の高いファイル検証方法の一つとして使われています。

偽装ファイルを見分けるには？

このツールで不審なファイルを分析する場合は、次の手順に従ってください。

  1. 「Upload Files」tab から不審な file をアップロードします。
  2. result の「File Format」が実際の file extension と一致しているか確認してください。
  3. 「⚠️ file extension が実際の format と一致しません」という警告が表示された場合は特に注意してください。
  4. 「Copy Signature」機能で証拠を記録するか、JSON / TXT report を download して保存できます。

典型的な偽装例は、悪意ある実行ファイルを画像や文書ファイルに見せかけることです。例えばファイル名が photo.jpg ファイルの Magic Number が 4D 5A（MZ executable signature）なら、実体は Windows executable file です。
