aspect ratio と size conversion に関するよくある質問

Aspect Ratio とは何ですか？

アスペクト比 画像の幅と高さの比率を表すもので、通常は「幅:高さ」という整数比で記述します。たとえば 16:9 幅が高さの約 1.78 倍であることを表します。

例：a 1920 × 1080 画像の幅と高さを最大公約数 120 で割ると、次の比率になります。 16 : 9。

アスペクト比は画像の形状を表示：

  • 16:9 — ワイドスクリーン、動画やテレビに最適
  • 4:3 — 正方形に近い従来型画面や古い写真
  • 1:1 — 完全な円。social post などでよく使われます。
  • 9:16 — 縦長 style で、スマートフォンの portrait video に適しています。
the 16:9 screen resolutions とは何ですか？

16:9 現在もっとも一般的なディスプレイ比率です。代表的な解像度：

  • 640 × 360 — nHD
  • 1280 × 720 — HD（720p）
  • 1920 × 1080 — Full HD（1080p）
  • 2560 × 1440 — 2K / QHD（1440p）
  • 3840 × 2160 — 4K / UHD
  • 7680 × 4320 — 8K

各 resolution level は前の 2 倍ですが、ratio は 16:9 を維持するため、同じ image を比例を保ったまま拡大できます。

💡 確認方法：任意の解像度をこのツールに入力し、次の表示になれば 16:9 これは標準的なワイドスクリーン比率です。

YouTube の推奨 video／thumbnail ratio は何ですか？

YouTube は複数の形式に対応しています。主な推奨事項は次のとおりです。

動画（一般）: 16:9 横長 - 1920×1080 または 3840×2160 を推奨

Shorts（短尺動画）:9:16 縦長 — 1080×1920 推奨

サムネイル：16:9 — 1280×720 を推奨、2MB 未満

サムネイルデザインの要点：

  • サムネイルはクリック率を左右する最重要要素の1つで、検索結果でも最も大きな視覚面積を占めます。
  • 重要なテキストや画像要素は中央の安全領域に収める、タイムスタンプやタイトルに隠れないようにします
  • 小さな画面でも読めるよう、高コントラストの色と大きめの font を使ってください。
Instagram post と story の size rule は何ですか？

Instagram は複数の post format に対応しており、それぞれ推奨 size があります：

  • 一般投稿（Post）：1:1 正方形 — 1080×1080
  • 縦向き：4:5 — 1080×1350
  • 横向き：16:9 — 1080×608
  • 期間限定ニュース（ストーリー）：9:16 — 1080×1920
  • Reels：9:16 縦向き — 1080×1920

💡 アップロードには可能な限り高解像度の画像（例：1080×1080）を使うことをおすすめします。Instagram 側で自動圧縮されるため、低解像度画像をアップロードすると拡大されてぼやける場合があります。

TikTok 動画のアスペクト比は？

TikTok と縦向き 9:16 が core ratio で、推奨 upload resolution は 1080 × 1920。

重要な注意事項：

  • TikTok は主にスマートフォンの縦画面で表示され、9:16 なら画面全体をほぼ埋められます。
  • Landscape（16:9）や square（1:1）の動画も upload できますが、上下に black bar が入るか、ユーザーが phone を回転する必要があります
  • 動画長は 21～34 秒程度を推奨し、最初の 2 秒で視聴者の注意を引く構成にしてください。
  • Safe area 設計：画面下部は UI に隠れる可能性があるため、重要な内容を配置しないでください。

💡 縦長動画を作る場合は、このツールの 9:16 変換機能を使って、任意サイズの素材を同じ比率へ調整できます。

205:78 のように、比率が整数にならない場合があるのはなぜですか？

すべての寸法を覚えやすい整数比へ落とし込めるわけではありません。たとえば Facebook cover image の推奨寸法は 820 × 312、最大公約数は 4 で、約分すると 205 : 78——これが実際の比率です。

💡 小数比率のほうが参考値として有用です。

820 ÷ 312 ≈ 2.63 — 幅がおよそ高さの 2.63 倍であることを意味します。

A4（210×297）≈ 0.71 — 幅が高さのおよそ 0.71 倍の比率を表します（縦長）。

既約整数比と小数比の両方を表示するため、どのようなサイズでも実際の比率を正確に把握できます。

画面比率（16:9、16:10、21:9、32:9）

16:9 現代のディスプレイで標準的なアスペクト比で、テレビ、プロジェクター、多くのコンピューターモニターに採用されています。YouTube や Netflix などの動画コンテンツも主に 16:9 です。16:10 16:9 より少し縦長で、以前のノート PC（MacBook Pro 16-inch、Microsoft Surface など）でよく見られる比率です。21:9 映画編集や没入型ゲームで使われる、シネマ向けの超横長比率です。32:9 16:9 screen 2 枚を横につないだ幅に相当し、multitasking や racing simulation game に適しています。

YouTube（16:9 と 9:16）

YouTube での一般的な動画利用 16:9(1920×1080) の一方で Shorts 短編動画 正立で使用 9:16（1080×1920）は、スマートフォンを縦向きで見る習慣に合わせた比率です。サムネイルは 16:9 の 1280×720 が固定サイズです。動画素材が別の比率の場合、YouTube では黒帯やクロップが発生する可能性があります。このツールの比率固定変換を使って、素材を適切なサイズへ先に調整できます。

Instagram（1:1、4:5、9:16）

Instagram で正方形投稿を使う方法 1:1（1080×1080）、正方形投稿に使用 4:5（1080×1350）、期間限定の動的コンテンツおよび Reels 用 9:16（1080×1920）。正しい ratio を選ぶと timeline 上で内容を完全に表示しやすく、不要な crop を避けられます。

TikTok（9:16）

TikTok と 9:16 縦型動画では 1080×1920 が中心で、スマートフォン画面を完全に埋められます。横長や正方形の動画もアップロードできますが、黒帯が入るなどして視聴体験が損なわれる場合があります。

Facebook と X（コミュニティバナー）

Facebook カバー画像の推奨事項 820×312（約 205:78）、X（Twitter）Banner 推奨サイズ 1500×500（3:1）。各 platform の推奨 size は将来変更される可能性があるため、使用前に最新の公式仕様を確認してください。

アスペクト比を計算するには？

Aspect Ratio は Width と Height の比率を求めて計算します。最大公約数（GCD）、その数で両辺を割ります：

例： 1920 × 1080

GCD(1920, 1080) = 120

1920 ÷ 120 = 16，1080 ÷ 120 = 9

結果：16 : 9

2 つの number に common factor がない（GCD = 1）場合、これ以上簡約できません。例： 1024 × 768 GCD は 256 なので 4:3 まで約分できます。一方、Facebook カバーの 820×312 のようなサイズは約分しても 205:78 と大きな整数比になるため、小数比 2.63 の方が直感的な参考値になります。

ベストプラクティス

  • エクスポート前に対象プラットフォームの比率を確認します — 各 platform には公式の推奨サイズがあります。まず preset list から対象を選び、その設定を素材へ適用してください。
  • 比率ロックを活用してください — Lock Aspect Ratio を有効にすると、target width を入力すれば正しい height を取得でき、その逆も可能です。
  • 非整数倍率のスケーリングを避ける — 画像を拡大縮小するときに縦横比を誤ると歪みます。先にこのツールで正しい寸法を計算してから resize してください。
  • 元の高解像度ファイルを保持します — 計算後に出力する場合は、最高解像度版から縮小すると最も良い画質を得やすくなります。
