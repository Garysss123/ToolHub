組み込み例を再現します

まず Wall area = 40、Block length = 390、Block height = 190、Joint width = 10、Waste = 5 に設定し、Concrete Block Wall Calculator を実行します。結果への影響を追跡できるよう、一度に変更する入力は 1 つにしてください。

壁面積、ブロック長、ブロック高、目地幅、ロス率を検証した後、結果を出力ワークスペースに表示し、該当するコピーまたはダウンロード操作を有効にします。

数式と変数の関係

壁面積とモジュールブロック寸法から必要なブロック数を見積もります。コンクリートブロックの計算では、ブロックのモジュール面寸法に目地幅を加えて使用します。角部、まぐさ、半端ブロック、補強部、施工時の破損は、選択したロス率に含めてください。実装式は「Math.ceil((wallArea/(((blockLength+joint)/1000)*((blockHeight+joint)/1000)))*(1+waste/100))」です。ページでは壁面積、ブロック長、ブロック高、目地幅、ロス率を検証してから、結果を pcs で表示します。

感度チェック：wall area だけを 40 m² から 44 m² へ変更します。他の入力を変えない場合、required blocks は 525 から 578 pcs へ変化します。入力から結果までを再現できる確認例です。
