数式と変数の関係

script の語数と発話速度から所要時間を見積もります。実装式は「words/wordsPerMinute」です。script word count と speaking rate を検証してから結果を min で表示します。

感度チェック: script word count だけを 1800 word から 1,980 word に変更します。他の入力を変えない場合、推定 speaking time は 13.85 分から 15.23 分へ変化します。入力と結果の関係を再現可能な形で確認できます。
