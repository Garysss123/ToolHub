Schema.org とは？ 構造化データ初心者向け完全ガイド

Schema.org は Google、Microsoft、Yahoo、Yandex が共同で策定した構造化データの語彙（Vocabulary）です。Web コンテンツの意味を機械が読み取れる形で表現できるよう、統一されたマークアップ規格を提供することを目的としています。構造化データでは、name、description、price、rating などの標準化されたプロパティを使い、商品、記事、イベント、組織などのエンティティを Web ページ上で記述します。

SEO において、構造化データは Rich Results の基盤です。Google は Product、FAQ、Recipe、Event など 30 種類以上の Rich Results をサポートしています。対応する構造化データを Web サイトに追加すると、検索結果に星評価、価格帯、Q&A プレビューなどの目立つ要素が表示される可能性があり、クリック率（CTR）の向上につながります。

JSON-LD 形式の完全チュートリアル

JSON-LD（JavaScript Object Notation for Linked Data）は、現在 Google が最も推奨している構造化データ実装方式です。Microdata や RDFa と異なり、JSON-LD は HTML 構造から完全に独立しています。 <script type="application/ld+json"> タグを埋め込んでも、ページの見た目や HTML 構造には影響しません。

標準的な JSON-LD 構造には 3 つの主要要素があります：@context（使用語彙の定義、固定： "https://schema.org"）、@type（WebSite、Article などのエンティティ型を定義）、そして属性キー値（type により name、description、url など）。JSON-LD は nested structure に対応し、product supplier や article author など複雑な関係も表現できます。

FAQ Schema 完全ガイド

FAQ Schema（FAQPage）は、Google Rich Results で広く使われている構造化データタイプの 1 つです。FAQ Schema を有効にすると、Q&A コンテンツが検索結果に直接表示される可能性があります。ユーザーがページを開かずに回答を得られるため利便性が高まり、検索結果での視認性向上にもつながります。

FAQ Schema の使い方 mainEntity 各質問と回答のグループを定義する attributes。各質問・回答グループには 質問（問題名）と AcceptedAnswer（回答本文）。Google は FAQ ページに少なくとも 2 組の質問と回答を含め、回答を完全で有用な内容にすることを推奨しています。注意：FAQ Schema は、ページの主要コンテンツ自体が Q&A 形式の Web ページにのみ適用してください。一般ページの一部分だけを FAQ としてマークアップするべきではありません。

Product Schema 完全ガイド

Product Schema は EC サイトに欠かせない構造化データです。有効にすると、検索結果に商品の価格、在庫状況、レビューの星評価、レビュー件数などのリッチ情報が表示される場合があり、検索結果上で商品の魅力を大きく高められます。Google の Product Rich Results では、価格表示、ショッピングボタン、レビュー情報などがサポートされています。

Product Schema の中核 required field には少なくとも 名前（商品名）と 提供（供給情報）。推奨フィールドには次が含まれます 説明（商品説明）、ブランド（ブランド）、sku（stock keeping unit）、画像（商品画像）、aggregateRating（レビュー概要）および レビュー（ユーザーコメント）。Product Schema の情報が完全であるほど、検索結果をより豊かに表示できます。

SoftwareApplication Schema 完全ガイド

SoftwareApplication Schema は、ソフトウェア製品やアプリケーション向けの専用構造化データ型です。モバイルアプリ、デスクトップソフト、Web アプリ、SaaS のいずれでも、この Schema を使ってソフトウェアの詳細情報を検索エンジンへ伝えられます。有効にすると、Google の検索結果にソフトウェア名、評価、対応 OS、価格、ダウンロードリンクなどのリッチ情報が表示される場合があります。

SoftwareApplication Schema を実装する場合は、次のフィールドを含めることをおすすめします。名前（ソフトウェア名）、説明（ソフトウェアの説明）、operatingSystem（Windows、macOS、Android など対応 OS）、applicationCategory（Game、Multimedia、DeveloperApplication などの application category）および 提供（price information）。software に user rating がある場合は、それも追加できます。 aggregateRating 平均評価を表示します。

BreadcrumbList Schema 完全ガイド

BreadcrumbList Schema（パンくずリストの構造化データ）は、サイト内ナビゲーションと検索結果表示を改善するための重要な仕組みです。設定すると、Google 検索結果でページタイトルの上に Home > Products > Laptops のようなナビゲーション経路が表示される場合があり、ユーザーがサイト内でのページ位置を理解しやすくなり、検索結果のクリック率向上にもつながります。

BreadcrumbList Schema は次を使用します itemListElement 各 navigation level を Array で定義し、各 element には @type: ListItem、位置（位置順、1 から開始）、名前（表示名）と 項目（対応 URL）。実装時は Breadcrumb の経路が実際のページ階層と一致していることを確認してください。Google は BreadcrumbList に少なくとも 2 項目を含め、最後の項目を現在のページにすることを推奨しています。
