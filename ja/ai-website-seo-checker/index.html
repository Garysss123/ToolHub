AI 改善提案

よくある質問

AI Website SEO Checker は、AI で生成された Web サイト向けに設計された SEO ヘルスチェックツールです。一般的な SEO ツールとは異なり、ChatGPT、Claude、Gemini、DeepSeek などの大規模言語モデル（LLM）がサイト構築時に見落としやすい Canonical タグ、構造化データ、Open Graph、Heading 階層などを重点的に確認します。さらに AI 向け特性の分析と具体的な改善提案を提供し、AI 生成サイトの検索エンジン性能向上を支援します。
広範なテストによると、AI 生成 HTML で最も抜けやすい SEO 要素には次のものがあります：(1) Canonical タグ — ほぼすべての AI は自動生成ではありません。（2） 構造化データ（Schema.org） — FAQ Schema、Breadcrumb Schema など。(3) Open Graph / Twitter Card — ソーシャル共有タグ；(4) 画像 ALT 属性 — AI 生成 image tag では ALT が欠けることがあります。(5) Meta Description — 短すぎたり、内容が繰り返しになる場合があります。（6） Robots Meta — インデックス制御タグです。基本的な要素に見えますが、SEO へ大きく影響する場合があります。
AI により高品質な HTML を生成させるには、プロンプトに具体的な要件を追加します。(1)「SEO 最適化を含む完全な HTML ページを生成してください」と明記する、(2)「canonical、meta description、Open Graph タグを追加してください」と指定する、(3)「すべての画像に ALT 属性を付けてください」と要求する、(4)「FAQ と Breadcrumb を構造化データ（JSON-LD）でマークアップしてください」と指定する、(5)「見出し階層を H1 → H2 → H3 の順に正しくしてください」と明記する、といった方法が有効です。要件を具体的に与えるほど、AI が出力する HTML の品質を高めやすくなります。
AI Readiness Score（AI 対応度スコア）は、このツール独自の評価指標で、Web サイトが AI 主導の検索エンジン（Google SGE、Bing Chat、Perplexity など）にとってどれだけ理解しやすいかを測定します。採点では、構造化データの充実度（AI が内容を理解しやすくする）、canonical タグの有無（AI がコンテンツの出典を混同するのを防ぐ）、意味論的な HTML 構造（AI が要点を抽出しやすくする）、コンテンツの機械可読性などを考慮します。スコアが高いほど、AI 検索エンジンに Web サイトの内容を正しく理解・提示してもらいやすくなります。
AI 生成 Web サイトではコンテンツ生成が速いため、重複または非常に類似したページが大量に生まれやすく、Canonical タグが特に重要になります。Canonical タグ（<link rel="canonical" />) は、どの URL がオリジナル版なのかを検索エンジンへ伝え、重複コンテンツによる SEO 評価の分散を防ぎます。さらに Google などの検索エンジンは、コンテンツの正規版を判断する際に Canonical をますます重視しています。AI 生成コンテンツはもともと独自性の課題を抱えやすく、Canonical がないと問題がさらに悪化します。
構造化データは、Google SGE、Perplexity、Bing Chat などの AI 主導型検索エンジンにおいて特に重要です。これらの AI 検索エンジンは回答を生成する際、正確な事実情報を抽出するために構造化データを優先的に参照します。たとえば FAQ Schema を使えば Q&A をユーザーに直接提示しやすくなり、Breadcrumb Schema はサイト階層の理解を助け、Article Schema は記事の著者・日付・トピックをより正確に識別するのに役立ちます。構造化データを欠く AI 生成サイトは、AI 検索での可視性が大きく低下する可能性があります。
AI サイト構築の特徴分析（AI Fingerprint）は、多数の AI 生成 HTML に見られるパターンを基に解析します。このツールでは、HTML 構造の完全性（AI は完全な構造の HTML を生成することが多い）、Meta タグの充実度（AI は Canonical を欠く場合がある）、構造化データの利用、Heading レベルの論理性（AI は概ね正しい）、画像 ALT の欠落率（AI は見落としやすい）、ソーシャル共有タグの充実度などを確認します。これは「このサイトが一般的な AI 出力の特徴にどの程度一致するか」を理解するための分析であり、サイトが AI 生成かどうかを断定するものではありません。

AI Web site 構築でよくある SEO 問題の完全分析

ChatGPT、Claude、Gemini、DeepSeek など大規模言語モデルの普及により、AI 支援または AI だけで Web サイトを作る開発者が増えています。ただし、AI が生成する HTML には SEO 面で共通しやすい弱点があります。

  • Canonical がありません: AI は Canonical タグを自動生成しないことが多く、重複コンテンツのリスクにつながります。
  • ソーシャル共有タグが不足しています: Open Graph と Twitter Card は無視されることがよくあります
  • 構造化データが不足：FAQ、Breadcrumb、Article などの Schema は自動追加されません
  • 画像の ALT 属性がありません: AI が生成する可能性があります <img> ただし ALT を含みません
  • Meta Description の品質が不安定です：生成結果が短すぎる、長すぎる、または他ページと重複する場合があります

対策は、プロンプトで SEO 要素を明示的に要求するか、このツールで生成後の検査と補強を行うことです。

AI により良い HTML を生成させるには

AI に SEO-friendly な HTML を生成させる鍵は prompt word の最適化（Prompt Engineering）です。以下は SEO 向け prompt の例です。

"繁体字中国語の完全な HTML page を作成してください。要件：
1. Contain SEO optimized <head>, including title, meta description, canonical
2. Open Graph（og:title、og:description、og:image）と Twitter Card タグを追加
3. 正しい Heading 階層（H1 → H2 → H3）を使用します
4. JSON-LD format で FAQ Schema と Breadcrumb Schema を追加します。
5. All <img> must contain the ALT attribute
6. viewport、charset、lang 属性を設定
7. favicon のリンクを追加"

このようなプロンプトを使うと、AI が生成する HTML の品質が大きく向上し、その後の手作業による修正を減らせます。

AI 検索エンジンにおける構造化データの重要性

AI-driven search の時代に、structured data の重要性はこれまで以上に高まっています：

  • Google SGE: AI が生成する検索要約では、構造化データを持つコンテンツが優先的に扱われる可能性があります。
  • Perplexity / Bing Chat：AI 検索エンジンは FAQ Schema を解析し、質問へ回答するときに正確な answer を提供します
  • Rich Snippets: 従来型 search でも structured data により、展開式 Q&A や breadcrumb path など rich format が検索結果へ表示される可能性があります。
  • AI 学習資料: 適切に構造化された構造化データは AI モデルの学習データに取り込まれる可能性があり、間接的にブランド露出の増加につながることがあります。

Schema.org markup は JSON-LD 形式で実装することを推奨します。これは Google を含む主要検索エンジンが推奨する形式です。

Heading 構造が SEO に与える大きな影響

Heading タグ（H1～H6）は Web ページ内容の骨格であり、SEO に大きく影響します：

  • AI がコンテンツを理解：Google SGE など AI 検索エンジンは Heading structure を通じてページの要点を抽出します
  • H1 は1つという原則: 各 page の H1 は 1 つだけにし、main keyword を含めてください。
  • ステップをスキップしない: 見出しは H1 → H2 → H3 の順に深くし、H1 から直接 H3 へ飛ばさないようにします。
  • AI 生成 FAQ：AI は複数 H1 や heading level の飛び越しを生成する場合があるため、特に確認が必要です
  • セマンティック化: Heading は装飾目的ではなく、content の theme を説明するために使ってください。

AI 生成 Web サイトでは Heading hierarchy 自体は正しいことが多い一方、H1 が複数存在する問題が起こる場合があります。このツールで素早く検出できます。

画像 SEO と AI 生成コンテンツ

AI 生成画像コンテンツには固有の SEO 課題があります：

  • ALT 属性: AI が生成した HTML では image に ALT attribute がないことが多く、最も一般的な見落としの 1 つです。
  • ファイル命名: AI が生成した画像リンクにはランダム文字列が含まれることがあるため、内容を表す説明的なファイル名へ変更してください。
  • 遅延読み込み: すべての画像に追加することを推奨します loading="lazy" パフォーマンスを改善
  • 画像サイズ: AI が生成する image tag に width/height がない場合、layout shift（CLS）が発生することがあります。
  • レスポンシブ画像：使用を検討 srcset 複数の解像度を利用できます

AI prompt に「すべての image に ALT attribute と size setting を含める」と指定することを推奨します。

AI 時代における Open Graph と Twitter Card の役割

ソーシャル共有タグ（Open Graph と Twitter Card）は、AI 時代において新たな重要性を持っています。

  • AI チャットボットの引用: AI chatbot が link を共有すると、OG tag を使って preview card が生成されます。
  • ソーシャルプラットフォームプレビュー: ChatGPT や Claude などの AI ツールも、リンクを埋め込む際に OG 情報を参照します。
  • OG：画像の重要性：AI-generated website では og:image が不足しやすく、共有時に image preview が表示されない場合があります。
  • Twitter Card：Twitter も OG に対応しますが、専用 Twitter Card tag のほうが表示を細かく制御できます

AI 生成 Web サイトでは OG タグの完全性に特に注意が必要です。og:image が欠けていると、共有時のプレビューが不安定になり、サイトの信頼感も損なわれやすくなります。
