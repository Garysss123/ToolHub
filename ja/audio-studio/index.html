よくある質問

この音声エディターは本当に無料ですか？
はい。完全無料で、インストールも登録も不要です。音声処理は Web Audio API と Canvas を使ってすべてブラウザ内で行われ、サーバー処理を必要としません。
audio file はサーバーへアップロードされますか？
いいえ。すべてのファイルは端末のメモリ内にだけ存在します。ページを閉じるか更新するとファイルは消えます。audio data をアップロード、保存、共有することはありません。
対応している音声形式は？
MP3、WAV、FLAC、OGG（Vorbis）、AAC、M4A（AAC）、WebM Audio（Opus）に対応します。書き出しは WAV（ロスレス）、OGG（非可逆圧縮）、低品質 MP3 を利用できます。
音声はどのくらいの長さまで編集できますか？
理論上の明確な上限はありませんが、主な制約はブラウザーのメモリです。快適に利用するには一般に30分未満の音声を処理することをおすすめします。より長い音声は分割した方が安定します。
音声を編集する方法は？
waveform 上をドラッグして範囲を選び、Trim、Delete、Copy を使用します。Trim field へ正確な start/end time を入力することもできます。
効果音はリアルタイムですか？
はい。すべてのエフェクトはリアルタイムで処理されます。EQ、Compressor、Reverb などを有効にすると変化をすぐに聴けます。最終エクスポート時には、これらのエフェクトが出力ファイルへ恒久的に適用されます。
マルチトラックミキシングに対応していますか？
軽量なマルチトラック機能に対応しています。複数の音声トラックを追加し、それぞれ音量調整、ミュート、ソロを設定し、最後に全トラックを1つのファイルへミックスして書き出せます。
このツールはどのブラウザに対応していますか？
最新の Chrome、Edge、Firefox、Safari に対応しています。特に長時間の audio や effect を扱う場合は、最良の性能を得るため Chrome または Edge の利用を推奨します。
キーボードショートカットには何がありますか？
Space = Play/Pause、Ctrl+Z = Undo、Ctrl+Y = Redo、Delete = 選択を削除、Ctrl+C = 選択をコピー、Ctrl+V = 貼り付け、Ctrl+D = 複製。
LUFS? Why is it important とは何ですか？
LUFS（Loudness Units relative to Full Scale）は、現代の音声ラウドネスに関する国際標準（ITU-R BS.1770）で使われる指標です。Spotify や YouTube などのストリーミングサービスも音量正規化に LUFS を使用しています。このツールでは、おおよその LUFS を推定し、音声全体のラウドネスを把握できます。

ブラウザーでの音声編集：Web Audio API の力

Mini Audio Studio は、現代のブラウザーが持つ音声処理能力を体験できるツールです。Web Audio API、Canvas 2D、OfflineAudioContext を組み合わせ、従来は Audacity や Logic Pro のようなデスクトップ DAW で行っていた処理の一部をブラウザー上で実現しています。

コア技術

Web Audio API W3C 標準のブラウザ音声処理 API で、AudioContext、AudioBuffer、BiquadFilterNode、DynamicsCompressorNode、ConvolverNode など豊富な処理ノードを提供します。これらのノードを自由に直列接続し、柔軟な音声処理パイプライン（Audio Graph）を構成できます。

OfflineAudioContext リアルタイム再生を行わず background で audio を高速 rendering できるため、effect 適用、audio analysis、export を短時間で完了できます。
