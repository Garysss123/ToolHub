数式と変数の関係

luminous flux を input power で割って luminous efficacy を計算します。実装式は「lumens/watts」です。luminous flux と input power を検証してから結果を lm/W で表示します。

感度チェック：luminous flux だけを 1600 lm から 1,760 lm へ変更します。他の入力を変えない場合、luminous efficacy は 106.67 から 117.33 lm/W へ変化します。入力から結果までを再現できる確認例です。
