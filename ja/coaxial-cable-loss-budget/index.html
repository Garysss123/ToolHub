Coaxial Cable Loss Budget の仕組み

Coaxial Cable Loss Budget は入力パラメーターから total loss を計算し、リアルタイム検証、読みやすい計算式の説明、ブラウザ内ローカル処理を提供します。

計算モデル

length に応じた cable attenuation と connector insertion loss を加算します。

利用例

制限と検証

計算は次のモデルに従います。ケーブル長による減衰とコネクタ挿入損失を加算します。実案件では追加の係数、許容差、税、規定、専門家レビューが必要になる場合があります。

組み込み例を再現します

Loss per 100 m = 6.8、Cable length = 30、Connector count = 2、Loss per connector = 0.2 から始め、Coaxial Cable Loss Budget を実行します。結果への影響を追跡できるよう、入力は 1 項目ずつ変更してください。

100 m あたりの loss、cable length、connector count、connector 1 個あたりの loss を検証した後、結果を出力ワークスペースへ表示し、コピーまたはダウンロード操作を有効にします。

数式と変数の関係

ケーブル長による減衰とコネクタの挿入損失を合算します。実装式は「loss*l/100+connectors*connectorLoss」です。ページでは 100 m あたりの損失、ケーブル長、コネクタ数、コネクタ 1 個あたりの損失を検証し、結果を dB で整形します。

感度チェック: loss per 100 m だけを 6.8 dB から 7.48 dB に変更します。他の入力を変えない場合、total loss は 2.44 dB から 2.644 dB に変化します。入力から結果までを再現可能な形で確認できます。

いつ使うべきか、結果をどう解釈するか

Coaxial Cable Loss Budget は、100 m あたりの損失、ケーブル長、コネクタ数、コネクタごとの損失を扱うワークフロー向けです。
