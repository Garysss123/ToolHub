Web Crypto 乱数と一様分布

一般的なインターフェースの視覚効果によく使用されます Math.random(), ただし unpredictability を目的に設計されたものではありません。この tool は crypto.getRandomValues() 暗号学的に安全な乱数を取得します。整数モードでは rejection sampling を使い、単純な剰余演算によって一部の数値がわずかに出やすくなる偏りを避けます。

Decimal モードでは、安全な乱数を指定範囲へ割り当てた後、選択した桁数に丸めます。「Allow Duplicates」をオフにすると、ツールは値を生成しながら重複を除外し、さらに現在の精度で十分な数の異なる値を生成できるかを事前に確認します。テストデータ、ランダム並べ替え、ゲームのプロトタイプ、一般的な抽選などに適しています。一方、賞金・規定・公開監査が関わる正式な抽選では、検証可能な記録を残せる専用手順を使用してください。

3 つのクイックモード

  • サイコロ：1～6の単一整数。
  • Lotto：1〜49 から重複しない整数を 6 個選び、昇順に並べます。
  • パーセンテージ：0～100、小数第 2 位まで丸めます。

よくある質問

Math.random() を使用していますか？
いいえ。生成と shuffle の両方で Web Crypto API を使用します。
なぜ might non-repeating patterns fail のですか？
指定した範囲と精度で生成できる異なる値の総数を、要求件数が超えている場合、その条件を満たすことはできません。
小数の結果は本当に偶数ですか？
このツールはまず一様分布へ mapping してから量子化します。一般用途には十分な分布ですが、極端な精度を求める科学シミュレーションでは専用の統計ライブラリを使用してください。
正式な抽選にも使用できますか？
技術的には安全な乱数源を利用できますが、正式な抽選にはルール、記録、第三者監査、地域の法令順守も必要です。
並べ替えると番号は再生成されますか？
いいえ。sort は既存 result の順序だけを変更し、safe shuffle も並び替えるだけです。
