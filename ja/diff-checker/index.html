よくある質問（FAQ）

Diff とは何ですか？
Diff は difference の略で、2 つのテキストを比較し、追加・削除・変更された箇所を見つける処理を指します。Diff ツールは Git diff のようなコードのバージョン管理、文書校正、データ比較などで広く使われています。中核となるアルゴリズムは Longest Common Subsequence（LCS）に基づき、どの内容が追加・削除・変更されたかを高精度に特定できます。
the difference between Line Diff, Word Diff and Character Diff とは何ですか？
行差分：行単位の変更比較は code や structured text の変更に最適で、最も一般的な Diff mode です。

単語差分: word 単位で比較し、article proofreading や Prompt comparison に適しています。各単語の変更まで確認できます。

文字差分：文字単位で比較します。最も細かな比較モードで、各文字の追加・削除まで表示できますが、大量のテキストでは読みづらくなる場合があります。

推奨：コードには Line Diff、記事には Word Diff、スペル変更を細かく特定したい場合は Character Diff を使います。
JSON Diff のベストプラクティスは？
「JSON mode」を有効にすると、左右の JSON を自動整形・並べ替えてから比較します。indentation や key order の違いによる誤判定を避けられます。

JSON を比較する際は「Ignore whitespace」も有効にすると、より見やすい差分になります。timestamp や UUID など動的な値が含まれている場合は、比較前に正規化しておくと差分ノイズを減らせます。
類似度はどのように計算されますか？
類似度は longest common subsequence（LCS）アルゴリズムで計算し、式は次のとおりです。

Similarity = (2 × LCS長度) / (左文字長度 + 右文字長度) × 100%

この指標は Dice 係数とも呼ばれ、100% に近いほど2つの文章が似ていることを示します。一般的には次のように解釈できます。
• 100%：完全に同一
• 80～99%：軽微な修正
• 50～79%：大幅な修正が必要
• < 50%：大部分が異なります
AI 生成コンテンツを比較するには？
このツールは、入力内容が AI プロンプト（システムプロンプト用語、キャラクター設定など）かどうかを自動検出し、Token 推定値と Prompt 専用統計を表示します。AI 生成コンテンツを比較する場合、LLM の出力は同義語や文構造の違いが多いため、Word Diff モードの利用を推奨します。

一般的な利用シーン：
• Prompt の異なる version 間で output の差を比較します。
• A/B テストで LLM の応答を比較
• fine-tuning 前後の model output を比較します。
Git の Diff はどのように動作しますか？
Git は内蔵 diff engine を使って file change を追跡します。実行すると git diff Git は、作業ディレクトリとステージング領域の内容（または 2 つのコミット間）を比較し、その差分を Unified Diff 形式で表示します。このツールでは同様の比較をより視覚的に行え、同期スクロールや色分けにも対応しているため、コマンドラインに不慣れな場合にも使いやすくなっています。
