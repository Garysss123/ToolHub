組み込み例を再現します

まず Reference amplitude = 1、Target amplitude = 2 に設定し、Amplitude Ratio to Decibels Calculator を実行します。結果への影響を追跡できるよう、一度に変更する入力は 1 つにしてください。

数式と変数の関係

電圧または音圧の振幅比に 20log10(A2/A1) を使用します。実装式は「20*Math.log10(a2/a1)」です。基準振幅と対象振幅を検証してから dB で結果を表示します。

感度チェック: reference amplitude だけを 1 から 1.1 に変更します。他の入力を変えない場合、amplitude difference は 6.021 dB から 5.193 dB に変化します。入力から結果までを再現可能な形で確認できます。
