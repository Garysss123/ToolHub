CSV → JSON 変換 FAQ

CSV and JSON format conversion and type judgment に関するよくある質問

CSV は汎用的な table format ですが、現代の多くの開発シナリオでは JSON が選ばれます：

  • API 開発： RESTful API、GraphQL、WebSocket などの通信 protocol は JSON を標準形式として広く使用します。CSV データを API へ取り込む場合は、先に JSON へ変換する必要があります。
  • NoSQL データベース： MongoDB、Firebase などは JSON file を利用するため、CSV は import 前に変換が必要です。
  • JavaScript / TypeScript： フロントエンドや Node.js プロジェクトは JSON をネイティブ対応しているため、そのまま import または JSON.parse()。
  • Python データサイエンス： Pandas は CSV を読み込めますが、機械学習モデルへの入力を含む多くの API レスポンスでは JSON が必要です。
  • AI／LLM ワークフロー： AI model training data、prompt template、Function Calling structure definition は通常 JSON を使用します。

CSV は基本的にすべてテキストですが、JSON は複数のデータ型を扱えます。自動型判定では各値に最適な型を推定します：

CSV 入力

name,age,active,score
Gary,30,true,95.5

出力を自動判定

{
  "name": "Gary",
  "age": 30,
  "active": true,
  "score": 95.5
}

変換ルール：

  • "true" / "false" → ボリンジャー値
  • "30"、"95.5"、"-5" → 数値
  • "null" → null
  • Null value → 設定した null value processing method に従って処理します。
  • 残り → 文字列

💡 CSV の元の文字列を型変換せず保持したい場合は「Treat all as string」mode を選択してください。

CSV field name に period が含まれる場合（例： profile.age、address.city）、Nested Object mode では自動的に nested JSON object へ展開されます：

CSV 入力（ドット記法）

profile.age,profile.city 30,Taipei

ネストされた Object の出力

{ "profile": { "age": 30, "city": "Taipei" } }

3つの出力モードを比較：

  • Object Array — 1件のデータを1つの object として array にまとめます。最も汎用性の高い preset mode です。
  • キー・バリューオブジェクト — 指定 field を Key、データ全体を Value として 1 つの object を出力します。
  • ネストされたオブジェクト — dot notation の field を複数階層の nested object へ自動展開します。

💡 dot notation のフィールドを検出すると、ツール上部に青い案内「Nested field detected (dot notation)」を表示します。

CSV を正しく解析する鍵は、区切り文字と BOM を適切に設定することです：

  • 区切り文字： Standard CSV uses a comma (,), but some spreadsheet tools (such as the European version of Excel) use a semicolon (;). If the data contains a lot of commas, Tab (\t) is a safer choice. This tool automatically parses the CSV based on the delimiters you choose.
  • UTF-8 BOM の自動検出： 一部の software（Excel が export する CSV など）は file 先頭に BOM tag を追加します（﻿）。「Automatic BOM Detection」を有効にすると BOM を自動識別・除去し、先頭列名に異常文字が入るのを防ぎます。
  • 空白をトリム: 有効にすると、各フィールドの前後にある空白文字を自動削除し、不要なスペースによるデータ比較エラーを防ぎます。

💡 CSV の最初の列名の先頭に不自然な文字がある場合は、「Automatic BOM Detection」を有効にしてください。

このツールは CSV の一般的な問題を自動検出し、line number と原因を表示します。

  • フィールド数が一致しません： 行の列数が header row（または先頭行）と一致しない場合、ツールは該当する行番号を正確に示し、その行の列数と期待される列数との差を表示します。
  • 空のフィールド： blank field value がないか確認し、その位置（row と column）を表示します。
  • ヘッダーを繰り返す: title column に同名 field がある場合、重複した Key は自動的に rename されます（例： name → name_2) JSON Key の一意性を確保するため。
  • 文法上の問題： 引用符が正しく対になっているか、意図しない改行が含まれていないかなどを確認します。

すべてのエラーはツール上部の Errors パネルに表示され、正確な行番号と列番号も示されるため、問題をすばやく修正できます。

CSV から JSON へ：data conversion と API integration の完全ガイド

現代の開発ワークフローでは、CSV（Comma-Separated Values）と JSONCSV と JSON（JavaScript Object Notation）は、それぞれ異なる役割を持つ代表的なデータ形式です。CSV は表計算ソフトやデータベースのエクスポートで一般的に使われ、JSON は API や NoSQL エコシステムの共通言語です。CSV から JSON への変換を理解することは、バックエンド開発、データエンジニアリング、AI アプリ開発の基本スキルです。

CSV とは何ですか？

CSV は最も古く、最も広く対応されているテキスト形式の表データ形式の一つです。設計は非常にシンプルです：1行に1レコード、1列に1項目を置き、特定の delimiter（通常はコンマ）で区切ります。。CSV の利点は汎用性——Excel、Google Sheets、database management system、Python Pandas など、ほぼすべてのデータ処理ツールが CSV に対応しています。

CSV はデータ出力（DB クエリ結果、財務資料、顧客リスト）、データ交換（異なるシステム間の一括インポート／エクスポート）、機械学習データセットなどで広く使われています。これらのデータを API、JavaScript、NoSQL データベースで利用する場合には JSON への変換が必要になることがあります。

JSON とは何ですか？

JSON は、次の形式を使用する軽量な構造化データフォーマットですキーと値のペア 付き配列 情報を整理するために使います。平面的な 2 次元構造の CSV と異なり、JSON は nested structure を扱えます。ネストされた階層、複雑なデータ関係を表現できます。JSON は Web API の事実上の標準形式となり、MongoDB など NoSQL database のネイティブデータ形式としても使われています。

JSON は string、number、boolean、array、object、null など複数のデータ型を扱えるため、すべての値がプレーンテキストになる CSV よりも、データの意味を正確に表現できます。

CSV と JSON の詳細比較

CSV

  • シンプルな構造のフラットな 2 次元テーブル
  • すべての値はプレーンテキストで、型情報はありません
  • Excel や表計算ソフトでネイティブ対応
  • 人が直接読み書きできます
  • 小容量ファイルと高い転送効率
  • ネストした構造を表現できません

JSON

  • ネスト構造と複雑なデータ関係に対応
  • string、number、Boolean、Null など複数の data type に対応します。
  • API と NoSQL データベースの標準形式
  • プログラムの解析効率が高い
  • 可読性が高く、デバッグに適しています
  • オブジェクト構造は CSV よりわずかに大きくなります

実用例：CSV → JSON 完全変換

CSV 入力

name,age,active,score,profile.city,profile.department Alice Chen,30,true,95.5,Taipei City,Engineering Bob Wang,35,false,87.0,Taichung City,Design

JSON 出力（Nested Object mode）

[ { "name": "Alice Chen", "age": 30, "active": true, "score": 95.5, "profile": { "city": "Taipei City", "department": "Engineering" } }, { "name": "Bob Wang", "age": 35, "active": false, "score": 87, "profile": { "city": "Taichung City", "department": "Design" } } ]

自動型判定では "30" 数値に変換 30，"true" ボリンジャーバンドに変換 true、ネストされたフィールド profile.city ネストされたオブジェクトへ展開します。

CSV to JSON の活用シーン

  • API データの準備： Excel の product list を CSV へ export し、JSON に変換して API 経由で front-end application へ提供します
  • NoSQL データベースのインポート： MongoDB mongoimport JSON 形式に対応しています。CSV はインポート前に変換が必要です
  • JavaScript / TypeScript 設定： CSV profile や translation table を code 内の JSON module へ直接変換します import 使用
  • AI / LLM 学習資料： 多くの AI モデルの学習データは JSON 形式で保存されます。CSV は fine-tuning で使う前に変換が必要になる場合があります。
  • データ移行： relational database から CSV へ export、JSON へ変換し、その後 file database へ migrate
