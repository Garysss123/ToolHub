Meta Tag FAQ

Meta Tag(Meta tag) is a special tag in the <head> of an HTML file that provides metadata about the web page to browsers and search engines. Although most meta tags do not appear directly on the web page, they are crucial to SEO:

• Title Tag: 検索結果の青い title は、SEO で非常に重要な要素の 1 つです。
• Meta Description：search result の summary text で、click-through rate に影響します。
• Open Graph / Twitter Card：SNS 上の共有プレビューを制御します。
• Canonical URL：duplicate content issue を防ぎ、search engine が正しい page を index できるようにします。

適切な Meta タグ設定は、検索結果での見え方、ソーシャル共有時の露出、ユーザーのクリック意欲を改善するのに役立ちます。
Open Graph（OG） Facebook が 2010 年に公開した共有用プロトコルで、Web ページを Facebook、LINE、LinkedIn などのソーシャルプラットフォームへ共有した際に、タイトル、説明、画像などのリッチなプレビュー情報を表示できるようにします。

• og:title: 共有タイトルをカスタマイズし、40～60 文字程度に収めることを推奨します。
• og:description: share description は 2～4 sentence、200 character 以内を推奨します。
• og:image: 画像を共有する場合は 1200×630 pixel を推奨します。クリック率の向上につながりやすいサイズです。
• og:type：Content type（website、article、product など）は platform が正しく表示する助けになります。

正しい OG tag を設定すると、SNS 上で Web サイトリンクを見栄えよく表示でき、魅力が高まり、social traffic の増加につながります。
Twitter Card X（旧 Twitter）の sharing preview protocol です。Open Graph と似ていますが、X platform 専用に設計されています。

• summary_large_image: large image mode。content Web site や blog に適しています。
• 概要: 小画像モード。個人情報ページやシンプルなページに適しています。

2 つの違い：
• OG は Facebook、LINE、LinkedIn、Slack など多くのプラットフォームで広く対応しています。
• Twitter Card が影響するのは X 上の共有プレビューのみです。
• ベストプラクティス: すべての platform で最適な共有表示を得るため、両方を設定してください。Twitter Card を設定していない場合、X は OG 情報を自動利用しますが、表示効果が弱くなることがあります。
Canonical URLCanonical URL（rel="canonical"）は、同一または非常によく似た内容へ複数の URL が存在するとき、どの URL を「公式」版として扱うかを検索エンジンへ伝えるために使います。

なぜ重要なのですか？
• duplicate content による SEO penalty を防ぎます。
• 検索ランキング評価を 1 つの URL へ集中させます。
• 一般的な例：https と http、www と non-www、UTM パラメーター付き URL、印刷版、ページネーションなど。

使用：
<link rel="canonical" href="https://example.com/original-page/" />

重複コンテンツの問題がない場合でも、各ページに自己参照 canonical URL を設定することはベストプラクティスです。
結論：Google は現在 Keywords Meta Tag をランキング要因として使用していません。

Google は 2009 年、Keywords Meta Tag をランキング要因として使用しないことを公式に発表しました。このタグが長年 SEO 業者によって乱用され、キーワード詰め込みに使われてきたためです。

• Bing / Yahoo: Keywords タグをランキング参考情報の一つとして利用する検索エンジンが残っている可能性はありますが、重みは非常に低いと考えられます。
• Yandex（Russia）：Keywords は場合によって参照価値があるとされています。
• Baidu（中国）：Keywords を補助的なシグナルとして使用する場合があります。

推奨事項：Keywords tag は残しても問題ありませんが（害はありません）、最適化に時間をかける必要はありません。Title、Description、コンテンツ品質、UX に注力するほうが正しい SEO 戦略です。
