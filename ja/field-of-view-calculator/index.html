数式と変数の関係

sensor width と focal length から rectilinear の水平 FOV を計算します。実装式は「2*Math.atan(sensor/(2*f))*180/Math.PI」です。ページでは sensor width と focal length を検証し、結果を ° で整形します。

感度確認：sensor width だけを 36 mm から 39.6 mm に変更します。他の入力をすべて同じにすると、horizontal field of view は 39.6 から 43.21 ° に変化します。入力と結果の関係を再現して確認できます。
