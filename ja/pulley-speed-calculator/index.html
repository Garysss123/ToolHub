プーリー出力回転数計算ツールの仕組み

Pulley Output Speed Calculator は指定したパラメータから出力速度を計算し、リアルタイム検証、読みやすい数式説明、ブラウザ内ローカル処理を提供します。

計算モデル

slip を無視し、pulley diameter ratio から output speed を換算します。

推奨ワークフロー

  1. すべてのフィールドが表示されている単位を使用していることを確認します。
  2. example value を調整し、live result と input summary を確認してください。
  3. 結果をコピーしたら、前提条件を記録し、使用前に要件を再確認してください。

利用例

input speed、driver diameter、driven diameter に関する計画、比較、文書化、簡易確認に利用できます。

制限と検証

この計算は、滑りを無視し、プーリー径の比から回転速度を換算するモデルに従います。実際のプロジェクトでは追加係数、公差、規格、専門家による確認が必要になる場合があります。

Input speed = 1750、Driver diameter = 100、Driven diameter = 250 を初期値として Pulley Output Speed Calculator を実行します。結果への影響を追跡できるよう、入力は一度に1項目ずつ変更してください。

input speed、driver diameter、driven diameter を検証した後、結果を出力ワークスペースへ表示し、対応する copy または download 操作を有効にします。

数式と変数の関係

slip を無視し、pulley の直径比から回転数を変換します。実装式は「input*d1/d2」です。入力回転数、driver diameter、driven diameter を検証してから結果を rpm で表示します。

感度確認：input speed だけを 1750 rpm から 1,925 rpm に変更します。他の入力をすべて同じにすると、output speed は 700 から 770 rpm に変化します。入力と結果の関係を再現して確認できます。
