ToolHub に問い合わせ

ツール改善に最も役立つのは、小さく再現可能な報告です。ToolHub はアカウント登録を必要とせず、この Web サイト上にメッセージを保存するフォームも提供していません。

最終更新：2026年9月2日

メール

レポート送信先 support@toolhuben.com。email は ToolHub の application database ではなく、利用中の email provider によって処理されます。

含める内容

正確な tool URL、browser と OS の version、機密情報を含まない sample input、期待した結果、実際に得られた結果を含めてください。表示上の問題では screenshot も有用です。

秘密情報を送信しないでください

パスワード、秘密鍵、access token、本人確認書類の全文、機密の顧客データ、ファイルの唯一のコピーは送信しないでください。問題を再現できる最小限のテストケースへ機密値を置き換えてください。

確認できる内容

報告対象には、計算エラー、形式処理、動作しないコントロール、キーボードやスクリーンリーダーのアクセス、モバイル表示、誤解を招く説明、プライバシー表記、重複ツールなどが含まれます。広告アカウントや第三者サービスに関する判断は、それぞれの提供者が管理します。

補正プロセス

再現可能な問題は、ページ上の前提と対象 standard に照らして確認します。重要な修正を行った後は、release 前に代表的な desktop、mobile、regression test を実施します。
