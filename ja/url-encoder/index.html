URL Encode/Decode ツールの完全ガイド

URL Encoding は、URL 内で特別な意味を持つ文字や安全でないバイトを % から始まる表記へ変換します。URL 全体、パス断片、クエリパラメーターでは許可される文字が異なるため、URL 全体を一律に再エンコードするのではなく、対象部分に応じた API を使う必要があります。

操作手順

  1. full URL、path、single parameter value のどれを処理するか判定します。
  2. 元のテキストを入力し、Encode または Decode を実行します
  3. %、+、&、=、Unicode character が receiver rule に適合するか確認します

実用的な提案と制限事項

JavaScript では、単一のパラメーター値には encodeURIComponent、完全な URL の組み立てには URL と URLSearchParams が適しています。内容が不明な入力をデコードする場合は、形式エラーも適切に処理してください。

プライバシーと端末内処理

URL と parameter は browser 内で変換されるだけで、対象 Web サイトへ送信されません。
