Hash と HMAC generators の完全ガイド

Hash は任意のデータを固定長 digest へ写像し、主に完全性の比較に使われます。HMAC は secret key を加えてメッセージの送信元と完全性を検証します。一般的な Hash は不可逆ですが、高速な Hash をそのままパスワード保存へ使うのは適切ではありません。

操作手順

  1. algorithm を選び、text、file、または HMAC key を入力します。
  2. summary を計算し、trusted source が提供した value と文字どおり比較します。
  3. 未知の digest だけを保存しないよう、algorithm 名と大文字・小文字の形式も記録してください。

実用的な提案と制限事項

ダウンロードファイルの検証には SHA-256 以上のアルゴリズムを推奨します。パスワードには Salt を付与し、Argon2、scrypt、bcrypt、PBKDF2 など専用の KDF を使用してください。

プライバシーと端末内処理

file は native streaming または browser API で計算され upload されません。HMAC key も page 外へ送信されません。
