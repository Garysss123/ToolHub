数式と変数の関係

Estimates monthly contributions from goal, current balance, term, and expected return. The implemented expression is “(()=>{const r=annualRate/100/12,n=months,targetGap=Math.max(0,target-current*Math.pow(1+r,n));return r===0?targetGap/n:targetGap*r/(Math.pow(1+r,n)-1)})()”. The page validates target amount, current balance, months remaining, expected annual return before formatting the result in TWD.

感度チェック：target amount だけを 1000000 から 1,100,000 へ変更します。他の入力を変えない場合、monthly contribution は 12,773 から 14,320 TWD へ変化します。入力から結果までを再現できる確認例です。
