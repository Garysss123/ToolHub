Gravel Weight Calculator の仕組み

Gravel Weight Calculator は入力パラメーターから gravel weight を計算し、リアルタイム検証、読みやすい計算式の説明、ブラウザ内ローカル処理を提供します。

計算モデル

loose volume に bulk density を掛け、metric tonnes を推定します。

推奨ワークフロー

  1. すべてのフィールドが表示されている単位を使用していることを確認します。
  2. example value を調整し、live result と input summary を確認してください。
  3. 結果をコピーしたら、前提条件を記録し、使用前に要件を再確認してください。

利用例

loose volume、bulk density を使う計画、比較、文書化、簡易チェックに利用できます。

制限と検証

計算は次のモデルに従います。ばら積み体積へかさ密度を掛け、メートルトンを推定します。実案件では追加の係数、許容差、税、規定、専門家レビューが必要になる場合があります。

数式と変数の関係

ばら積み体積にかさ密度を掛けてメートルトンを推定します。実装式は「volume*density/1000」です。ページではばら積み体積とかさ密度を検証してから、結果を t で表示します。
