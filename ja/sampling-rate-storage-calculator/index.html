数式と変数の関係

sample rate、bit depth、channel 数、duration から PCM ストレージ容量を見積もります。実装式は「rate*bits*channels*seconds/8/1000000」です。各入力を検証してから結果を MB で表示します。

感度確認：sample rate だけを 48000 Hz から 52,800 Hz に変更します。他の入力をすべて同じにすると、uncompressed size は 86.4 から 95.04 MB に変化します。入力と結果の関係を再現して確認できます。
