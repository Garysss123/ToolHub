Unix Timestamp 変換ツールの完全ガイド

Unix Timestamp は 1970-01-01 00:00:00 UTC からの経過時間を表し、一般に秒またはミリ秒を単位とします。変換で混同しやすいのは単位とタイムゾーンです。Timestamp 自体はある一瞬を示し、整形した日時文字列はタイムゾーンによって異なる日付・時刻として表示されます。

操作手順

  1. 元データが秒、ミリ秒、または別の精度なのか確認してください。
  2. timestamp または date を入力し、表示したい time zone を選択します
  3. database や API で使う前に UTC と local result を比較してください。

実用的な提案と制限事項

タイムゾーン情報のない日付文字列を勝手に解釈しないでください。システム間の受け渡しには、Z またはオフセットを明示した ISO 8601 の利用を推奨します。また 32 ビット秒数の表現範囲にも注意が必要です。

プライバシーと端末内処理

date と timestamp はブラウザ内でローカル変換され、schedule や record は送信されません。
