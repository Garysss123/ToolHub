Image Forge 完全ユーザーガイド：画像のトリミングと拡大縮小

画像の切り抜き・リサイズツールを使うと、Web サイト、SNS、アバター、文書などの用途に合わせて構図を調整できます。クロップでは画像内容の一部が失われ、拡大しても元画像に存在しない細部を本当に生成することはできません。可能な限り高解像度の元画像から始めてください。

操作手順

  1. original image を追加し、free crop または fixed aspect ratio を選択します。
  2. crop box、output size、format を調整し、composition focus を確認します。
  3. download 前に edge と text を 100% 表示で確認してください。

実用的な提案と制限事項

サムネイル化の前に適度なシャープ処理を行えますが、過度に強めるとハローが発生します。透明背景の素材は PNG または WebP、写真は画質要件に応じて JPEG で出力すると扱いやすくなります。

プライバシーと端末内処理

画像編集と出力にはネイティブ Canvas を使用し、素材はアップロードされません。
