Display Interface Bandwidth Calculator 完全ユーザーガイド

表示帯域幅は、水平・垂直ピクセル数、リフレッシュレート、1 ピクセルあたりのビット数、転送プロトコルのエンコードや blanking overhead に左右されます。計算結果から、特定の表示モードがインターフェース上限にどれほど近いかを概算できます。

操作手順

  1. resolution、refresh rate、color depth、color sampling setting を入力します。
  2. 生の Pixel Data Rate を、Overhead を含む必要帯域と比較します。
  3. graphics card、screen、cable、port が対応する specification を比較します

実用的な提案と制限事項

インターフェースの公称帯域幅が、そのまま画像データに使える帯域幅を意味するわけではありません。DSC、クロマサンプリング、タイミング形式によって実現可能なモードが変わり、最終的には機器チェーン全体のネゴシエーション結果が優先されます。

プライバシーと端末内処理

すべての parameter と計算は browser 内で行われ、hardware data を検出・送信しません。
