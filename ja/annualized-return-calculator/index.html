数式と変数の関係

指定日数で得た総収益率を複利ベースで年率換算します。実装式は「(Math.pow(1+totalReturn/100,365/days)-1)*100」です。ページでは保有期間収益率と保有日数を検証し、結果を % で整形します。

感度チェック: holding-period return だけを 12% から 13.2% に変更します。他の入力を変えない場合、annualized return は 18.81% から 20.751% に変化します。入力から結果までを再現可能な形で確認できます。
