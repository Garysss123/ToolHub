MangaLens 隱私權政策

最後更新日期：2026年3月

歡迎使用 MangaLens 網頁漫畫 AI 翻譯擴充功能（以下簡稱「本工具」）。我們極度重視您的隱私權。本工具的系統架構設計基於「本地優先（Local-First）」與「資料最小化」原則。本政策將向您詳細說明我們如何處理您的資料。

1. 核心聲明：我們「不」收集您的資料

本工具為純前端（Front-end only）應用程式，開發者並未架設任何後端伺服器來收集您的資料。我們不收集、不儲存、也不會向任何開發者伺服器傳送您的個人識別資訊、瀏覽紀錄或截圖內容。

2. 畫面截圖與圖像處理

當您使用快捷鍵觸發翻譯功能時，本工具會擷取您指定框選的網頁區域。這些圖像數據（Base64）僅會在您的本機瀏覽器記憶體中進行短暫處理，並透過加密連線 (HTTPS) 直接傳送至您親自指定的 AI 服務供應商（如 OpenAI、Google Gemini）或您本機的伺服器（如 localhost 的 Ollama/LM Studio）。我們無法攔截、讀取或備份您的任何圖像資料。

3. API 金鑰 (API Key) 的儲存

為了讓本工具能夠呼叫您指定的雲端 AI 服務，您輸入的 API 金鑰將僅加密儲存於您本機設備的瀏覽器儲存空間中（使用 chrome.storage.local API）。

  • 您的金鑰絕不會被上傳或備份至我們的伺服器。
  • 您的金鑰不會與您的 Google 帳號進行跨裝置同步（我們故意不使用 sync API 以確保物理隔離）。
  • 您可以隨時在擴充功能的設定面板中一鍵清除這些金鑰資料。

4. 第三方服務與資料分享

本工具的作用為「通訊橋樑」。當您選擇使用 OpenAI (GPT) 或 Google (Gemini) 等雲端模型時，您的截圖資料與翻譯請求將受限於該服務供應商的隱私權政策。我們強烈建議您不要使用本工具擷取或翻譯包含極度機密或個人敏感資訊的畫面。

如果您選擇使用「本地端模型（Localhost / Ollama / LM Studio）」，則所有的資料傳輸與神經網路運算皆在您的實體設備上離線完成，實現 100% 的絕對隱私隔離。

5. 權限使用說明

  • 主機權限 (<all_urls>)： 用於確保本工具能在您存取的任何漫畫或圖像網站上運行，並允許向您指定的 AI API 發送跨來源請求 (CORS)。
  • activeTab： 用於在您主動觸發時，擷取當前分頁的可視區域以進行圖像翻譯。
  • storage： 用於在您的本機安全地儲存您的 API 金鑰與介面偏好設定。

6. 聯絡我們

如果您對本隱私權政策、資料處理架構，或是 MangaLens 的運作機制有任何疑問，請透過 Chrome 線上應用程式商店的支援頁面，或開發者提供的聯絡管道與我們聯繫。
