Base64 編解碼工具完整使用指南

Base64 把二進位資料表示為可安全放入文字通道的字元，但它不是加密，也不會保護內容。常見用途包含 Data URL、Email 附件與 API 欄位；編碼後體積通常會增加約三分之一。

操作步驟

  1. 選擇編碼或解碼模式並輸入文字或檔案
  2. 確認 UTF-8、Data URL 前綴與換行需求
  3. 轉換後檢查輸出類型，再複製或下載

實務建議與限制

不要把密碼、Token 或個資只做 Base64 後公開，任何人都能還原。處理大型檔案時，文字表示會增加記憶體與傳輸成本。

隱私與本機處理

文字與檔案由瀏覽器本機編解碼，不會上傳。
