Hash 與 HMAC 產生器完整使用指南

Hash 將任意資料映射為固定長度摘要，常用於完整性比對；HMAC 再加入秘密金鑰，可驗證訊息來源。一般雜湊不可逆，但快速雜湊不適合直接儲存密碼。

操作步驟

  1. 選擇演算法並輸入文字、檔案或 HMAC 金鑰
  2. 計算摘要並與可信來源提供的值逐字比對
  3. 紀錄演算法名稱與大小寫格式，避免只保存不明摘要

實務建議與限制

下載檔校驗建議使用 SHA-256 或更強演算法。密碼應使用 Argon2、scrypt、bcrypt 或 PBKDF2 等專用 KDF 搭配 salt。

隱私與本機處理

檔案以本機串流或瀏覽器 API 計算，不會上傳；HMAC 金鑰也不會離開頁面。
